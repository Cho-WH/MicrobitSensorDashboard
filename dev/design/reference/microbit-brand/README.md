# micro:bit 공식 자산 보관 및 배치 검토

2026-10-25 공식 사이트에서 확보했다. 이 보관 디렉터리는 정적 빌드의 복사 대상이 아니다. V2 호환성 PNG 원본만 public/assets/branding/에 복사해 상단 제목바에 적용했다. 앱 대표 로고는 별도로 제작한다.

## 원본과 권리

- 출처: [공식 브랜드 지침](https://www.microbit.org/brand-guidelines/). 개별 다운로드 URL·SHA-256·크기는 [manifest.json](manifest.json)에 기록한다.
- 권리자: Micro:bit Educational Foundation. 저장소의 MIT 라이선스를 이 자산에 적용하지 않는다. 공식 지침에 따른 사용만 허용되며, 보관이 앱 로고 사용 허락을 뜻하지 않는다.
- `brand-guidelines-2023-11.pdf`: 공식 페이지가 현재 연결하는 2023년 11월 시각 지침 원본. 다운로드 날짜와 문서 발행 날짜를 구분한다.
- `compatibility-logos.zip`: 공식 호환성 로고 전체 원본. `v2-only-transparent.png`는 ZIP에서 변경 없이 추출한 V2 투명 PNG다.
- `works-with-v1.png`, `works-with-v2.png`, `works-with-v1-v2.png`: 공식 안내 페이지의 표시용 원본 이미지다. V1 관련 파일은 참고용 보관이며 앱 지원 선언이 아니다.
- `official-logo-reference.svg`: 공식 기호와 글자가 결합된 로고의 참고용 원본. 별도 허용된 텍스트 워드마크 파일로 취급하지 않는다.

워드마크는 `micro:bit`이라는 이름을 뜻한다. 호환성 설명은 일반 글자로 `works with the BBC micro:bit`을 쓰는 방식이 공식 지침에 제시되어 있다. 기기 이름의 m은 소문자로 쓴다. 일반 로고와 호환성 로고의 사용 조건은 서로 다르다. 공식 로고를 자르거나 다시 색칠해 앱 로고에 합치지 않는다. 실제 적용 시에는 원본 여백·비율·표현 지침과 출처 표시를 함께 확인한다.

## 배치 제안 — 미적용

현재 `src/device/firmware.js`의 다섯 펌웨어는 모두 `micro:bit-v2`를 지원 대상으로 선언한다. 이는 구현 계약이며 이번에 실물 호환성을 새로 검증했다는 뜻은 아니다.

| 위치 | 제안 | 목적 |
|---|---|---|
| 사이드바 상단 | 새 독자 기호 + 센서 실험실 | 앱의 정체성을 표시한다. 공식 표장을 결합하지 않는다. |
| 홈 소개 문장 아래 | BBC micro:bit와 함께 사용하는 센서 실험 도구 | 처음 방문한 학생에게 사용하는 장치를 알려 준다. |
| 준비 화면의 장치/프로그램 정보 | V2 호환성 로고 한 번 + 필요한 경우 micro:bit V2 안내 | 장치를 고르고 프로그램을 설치하는 시점에 필요한 정보를 준다. |
| 앱 정보·도움말 | 공식 영문 호환 문구, 재단 출처와 공식 사이트 링크 | 자세한 지원 범위와 출처를 찾을 수 있게 한다. |

우선 권장 조합은 **홈의 짧은 설명 + 준비 화면의 V2 표시 + 앱 정보의 출처**다. 측정·분석 화면에는 반복하지 않는다. 모바일에서는 장치 안내 흐름 안에 배치하고, 배지를 담기 위한 별도 둥근 테두리 카드를 추가하지 않는다. 공식 호환성 표시는 새 앱 로고와 충분히 분리한다.

## 현재 적용 범위

왼쪽 패널의 센서 실험실 바로 위에 작은 `micro:bit` 글자만 배치했다. 기존 로컬 Pretendard 서체의 650 굵기·소문자·콜론을 사용하며 이름 내부 줄바꿈을 막는다. 기존 앱 기호와 하단의 `micro:bit · 센서로 만나는 과학` 문구는 유지한다.

홈·미리보기·준비 화면에 추가했던 호환성 안내·재단 링크·출처 영역은 사용자 요청으로 모두 원상복구했다. 위 배치 제안은 미적용 참고안이며 일반 공식 로고는 보관만 한다. 이후 사용자 승인으로 V2 호환성 로고를 상단 제목바에서 모든 조작 버튼 뒤, 맨 오른쪽에 적용했다. 버튼과 같은 36px 높이로 표시하고 불투명도 70%로 보조 정보의 위계를 준다. 원본 파일은 변경하지 않는다. 모바일(760px 이하)에서는 숨기고, 그보다 넓으면 제목·상태·현재 표시되는 도구·로고의 실제 한 줄 폭과 간격을 합산하여 여유가 있을 때 표시한다. 사이드바 하단 문구는 12px·550 굵기·남색을 사용하며 가운데 점을 제거하고 상하 여백을 8px로 줄였다.
