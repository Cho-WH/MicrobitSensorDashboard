# Bluetooth 실험 기록

Git에는 핵심 집계(`*-summary.json`)와 설계 문서의 검증 결과만 보관한다. 원본 JSON 로그는 이 폴더에 로컬로 보존하며 `.gitignore`로 추적에서 제외한다. 누적 로그를 다시 커밋하지 않는다.

- 부분 교체: `2026-10-27-gugav-partial-backoff-summary.json` — 16왕복·32회 성공, 자동 복구 6건.
- 전체 교체: C 2왕복·4회 성공. 전송 24.688–26.862초, 설치 후 재연결 4.683–5.268초.
- 위 실물 결과는 서비스 조회 제한을 2초로 줄이기 전 기록이다.
- 상세 원본 파일명은 집계에 남아 있으나 다른 체크아웃에는 원본이 없을 수 있다.

이전에 이미 커밋된 원본은 과거 이력에 남지만 현재부터 추적하지 않는다.
