실행 모드 → 비본딩 DFU 진입 → 전체 전송 → 프로그램·수신 확인

기존 부분 교체 시험
처음 한 번 USB 준비

아래 C 파일을 MICROBIT 드라이브에 복사하세요. OS 페어링은 하지 않습니다. 다른 앱의 측정을 마치고 연결을 해제하세요. 이번 전체 전송은 런타임과 프로그램을 바꾸며 Bluetooth 스택·부트로더는 바꾸지 않습니다.

실험 파일을 확인하고 있습니다.

로컬 제어 꺼짐

1. 시험본 C 준비·연결

브라우저의 장치 선택 권한과 OS 본딩은 다릅니다. 기존 본딩 기록이 있다면 먼저 로그에 남기고 별도 조건으로 다루세요. 이 실험 화면은 기록을 삭제하지 않습니다.

선택한 보드 없음

2. 비본딩 DFU 진입

일반 실행 모드에서 UUID 0003을 확인한 뒤 진입합니다. 본딩형 UUID 0004로 대신 진행하지 않습니다.

3. DFU 보드 선택·전체 전송

라이브러리 비교: web-bluetooth-dfu 2.4.0 기본 설정 · 별도 전송 속도 제한 없음. 이전 6분 성공 기록과 다른 전송기입니다.

2번 진입 직후 이 버튼으로 장치를 선택하세요. 대기 시간이 길어지면 일반 실행으로 돌아갈 수 있습니다. 이름은 DfuTarg 또는 기존 보드 이름으로 보일 수 있습니다. 한 대만 켠 실험 조건에서 진행합니다.

아직 전송하지 않음

4. 실행·측정 확인

재연결 후 같은 보드의 일반 실행·프로그램 식별값을 확인하고 측정값 3개를 받습니다. 재연결이 실패하면 1번의 보드 선택으로 다시 선택할 수 있습니다.

수신 전

권장 순서: 온도 자기 재설치 → 밝기 → 온도. 실패 시 로그를 저장하고 C HEX를 USB로 다시 설치해 복구합니다.
