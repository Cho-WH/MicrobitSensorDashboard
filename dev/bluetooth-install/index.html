자동 시험

연결 비교는 프로그램 전송 없이 재시작 후 첫 연결만 확인합니다. 교체 시험은 부분 전송·프로그램 확인·측정값 수신을 이어서 실행합니다.

    로컬 제어 꺼짐

    로컬 제어를 켜면 화면 조작 없이 실행·결과 조회가 가능합니다. 새로고침하면 다시 켜야 합니다. 자동 시험은 등록된 시험본에서만 시작하며, 물리적 정확도·전원 차단 복구는 별도 확인합니다.

    설치 모드 확인

    상단의 무선 교체용 시험본 B 받기로 최초 USB 설치를 준비합니다. 시험본의 런타임 식별값은 5f21a4c8e2b240e5입니다.

    A와 B를 누른 채 뒷면 리셋 버튼을 눌렀다 놓고, LED 표시가 나타날 때까지 A와 B를 유지합니다. 연결이 끊기면 선택 장치 재연결로 모드를 다시 읽으세요.

    현재 배포본은 pairing_mode: 0입니다. 표준 모드 진입이 안 될 수 있습니다. 모드가 0이면 설치 대기, 1이면 일반 실행입니다.

    V2·전송 서비스·현재 모드를 확인해야 요청할 수 있습니다.

    요청 전송이나 연결 해제만으로 전환 성공을 판정하지 않습니다. 재연결 후 읽은 모드로 확인합니다. 시험본 확인은 사용자 입력이며 펌웨어 자동 식별이 아닙니다.

    종료한 전체 DFU 조사
    3

    전체 애플리케이션 교체

    런타임부터 센서 프로그램까지 처음부터 전송합니다. 부트로더와 Bluetooth 시스템 영역은 포함하지 않습니다. 먼저 온도 → 온도 재설치, 그다음 밝기 → 온도로 확인합니다.

    DFU는 페어링 기록이 필요한 경로일 수 있습니다. 진입·권한이 거부되면 우회하지 않고 로그에 남깁니다. 현재 시험본의 보안 설정은 변경하지 않습니다.

    파일 SHA-256·객체별 CRC를 확인합니다. 종료 응답 뒤 원래 보드에 재연결해 프로그램·온도 수신을 확인합니다. 전원을 유지하세요. 연결 해제는 중단이며 자동 재개하지 않습니다. 실패 시 USB로 복구하세요.

    수동 부분 전송 시험
    3

    시험 프로그램 무선 전송

    설치 모드로 전환한 뒤 선택 장치 재연결을 누르세요. 런타임이 같은 검증된 시험 파일만 전송합니다.

    설치 모드로 연결한 뒤 시험 파일을 전송합니다.

    전송 중 전원을 유지하세요. 연결 해제는 전송을 중단합니다. 중단 시 재전송 또는 USB 복구가 필요할 수 있습니다. 100% 전송 뒤에도 재연결해 프로그램을 확인합니다.
