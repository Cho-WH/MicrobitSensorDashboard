# 앱 글꼴

Pretendard 1.3.9를 파생한 `Sensor Lab Sans`를 사용한다. 원본은 `public/vendor/pretendard/PretendardVariable.woff2`이며 SIL OFL 1.1과 저작권을 보존한다. 예약된 폰트 이름은 파생 파일 내부에서도 변경한다.

- **core**: Pretendard 1.3.9의 `subset_glyphs.txt`에 있는 고정 기본 문자 목록. 원본에서 지원하는 3,728자(한글 2,780자, 영문·숫자·과학 기호·자모 등)를 포함한다. 화면 문구를 추출해 범위를 결정하지 않는다. 이 파일 하나를 조기 요청하고 준비한 뒤 앱을 표시한다.
- **extended**: 원본이 지원하는 나머지 10,608자. 필요할 때만 요청하며 `font-display: optional`로 늦은 글꼴 교체를 피한다. 준비되지 않은 문자는 시스템 글꼴로 읽을 수 있다. 원본이 지원하지 않는 문자도 시스템 대체 글꼴을 이용한다.
- 원본이 가진 모든 코드포인트를 중복 없이 나누고 가변 굵기를 유지한다. 생성 시 SHA-256을 파일명에 넣고 manifest에 출처·크기를 기록한다.

재생성: Python 환경에 `python -m pip install -r dev/fonts/requirements.txt`로 도구를 설치한 뒤 `python dev/fonts/build.py`를 실행한다. 생성된 두 WOFF2, CSS, manifest, LICENSE를 검토해 함께 반영한다. 일반 앱 빌드와 CI는 Python을 사용하지 않는다. 재생성 후 사용하지 않는 이전 해시 파일은 참조를 확인하고 정리한다.

기본 폰트는 HTML preload로 요청한다. 앱은 초기화 시 최대 1.5초 기다린 뒤 그 문서에서 쓸 글꼴을 고정한다. 실패·시간 초과 시 시스템 글꼴을 유지하며, 늦은 다운로드 완료로 앱 전체를 교체하지 않는다. Canvas는 최초 생성 전에 이 결정을 공유하고, 관계없는 폰트 로딩마다 전체 그래프를 갱신하지 않는다. 출력 시에는 해당 문서의 추가 문자 로딩을 제한 시간 안에서 기다린다.

2026-10-31 로컬 Cloudflare/Chromium 확인: 홈의 기본 폰트 요청 1개, 화면 공개 후 추가 폰트 요청 0개, 새로고침의 폰트 전송 0바이트. 1366px 데스크톱과 390px·1.6Mbps·100ms 지연·CPU 4배 감속 조건에서 최초 접속/새로고침의 관측 CLS는 0이었다. 느린 첫 접속에서는 시스템 글꼴을 유지하고 다음 접속에 캐시된 앱 글꼴을 사용했다. 실제 휴대폰·Safari 결과나 운영 배포 후 성능을 나타내는 수치는 아니다.
