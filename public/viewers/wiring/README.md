# 공통 배선 뷰어

`index.html?sensor=bmp280` 또는 `index.html?sensor=ds18b20`을 연다.
앱 안내에서는 `embed=1`을 더하며 보기 선택·단계는 부모 GuideView가 소유한다.
등록된 센서만 선택할 수 있고 임의 URL·모델·코드를 메시지로 주입하지 않는다.

`prepare → ready`, `apply-state → applied` 순서의 `sensor-lab-wiring` v1 메시지를 사용한다.
요청 ID, 같은 origin·source와 응답 단계를 확인한다. 상태에는 시점, 강조할 배선 ID,
분리 정도, 센서 정의의 보기 선택값만 넣는다. 보기 조작은 준비 확인이나 장치 명령을 보내지 않는다.
WebGL 컨텍스트 손실은 `unavailable`로 부모에 전달하며 배선표·재시도를 유지한다.

부품·연결 구성·재질 수명·새 확장 보드 등록 경계는 [공통 장치 자산](../../assets/devices/README.md#외장-센서-연결-구성)을 따른다.
Three.js와 기존 부품 형상 출처는 [BMP280 이식 기록](../bmp280/README.md)에 보존한다.

2026-10-29: 배선 경로·어댑터 연결·묶음 핀 순서·대체 보드 매핑의 단위 검사,
BMP280/DS18B20 준비·지연 로딩·실패 복구, 320px/데스크톱 DS18B20 모의 기록·분석을 확인했다.
DS18B20 안내는 개별 점퍼선으로 고정한다. 실물 SEN050007 치수 정밀 대조, 실제 연결선 체결과 DS18B20 수신 확인은 아직 수행하지 않았다.
