케이블 선택 방법

I²C는 두 신호선으로 센서와 micro:bit가 정보를 주고받는 통신 방식입니다. 사용할 단자 모양을 골라 보세요.

케이블의 핀이 튀어나온 끝(수)을 sensor:bit 소켓에 꽂고, 구멍이 있는 끝(암)을 센서의 핀에 끼웁니다.

선의 역할 자세히

이름을 눌러 선의 역할과 연결 위치를 확인하세요. 다시 누르면 강조가 풀립니다. 체크를 해제하면 해당 선만 숨길 수 있습니다.

연결 상태

막대를 오른쪽으로 움직여 케이블을 뽑아 보세요. 아래쪽에서 보면 핀이 튀어나온 끝(수)과 구멍이 있는 끝(암)을 구별할 수 있습니다.

연결할 때 확인할 점

선의 색은 케이블마다 다를 수 있습니다. 기판에 적힌 이름을 보고 V–VCC, G–GND, CL–SCL, DA–SDA를 연결하세요. 전원(V)과 접지(G)는 두 기판에서 순서가 달라 선이 서로 교차합니다.

CSB·SDO의 연결 방법은 센서 제품에 따라 다릅니다. 실험에 사용하는 제품은 선생님의 안내에 따라 연결하세요.

실제 장치를 연결한 뒤, 측정용 앱에서 온도와 압력이 표시되는지 확인하세요.

화면 조작

작은 화면에서는 아래의 배선 / 연결·분리 / 도움말 메뉴를 사용하세요. 모델 크게를 누르면 조작부가 접히며, 메뉴를 누르면 다시 펼쳐집니다. 체크는 선의 표시 여부를 바꾸고, 카드는 선을 강조합니다.

마우스: 드래그로 회전, 휠로 확대·축소, 오른쪽 드래그로 이동합니다. 터치: 한 손가락으로 회전, 두 손가락으로 확대·이동합니다.

키보드: Tab 키로 3D 화면을 선택한 뒤 방향키로 회전하고, + / −로 확대·축소합니다. Home 키를 누르면 처음 시점으로 돌아갑니다.
