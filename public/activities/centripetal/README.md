# 구심가속도 실험 방법 그림

2026-10-31 · 공통 실험 방법 안내에 쓰는 4단계 그림. 내장 image_gen 도구로 직접 제작했다.

- `experiment-placement.png`: 원판·보드·배터리·고정 자석과 반지름. 보드와 칩은 개념도이며, 실제 칩 위치는 장치 준비 안내에서 확인한다.
- `experiment-recording.png`: 회전 속도가 안정된 부분을 찾는 개념 그래프. 두 물리량의 세로 범위는 다르며 수치 비교용이 아니다.
- `experiment-range.png`: 같은 특징 여섯 개 사이의 다섯 간격을 세고, 동일 구간에서 평균 가속도와 주기를 얻는다. 실제 한 바퀴에 대응하는 특징을 확인했다는 전제의 예시다.
- `experiment-analysis.png`: 센서 측정값과 회전 주기를 이용한 두 계산 경로와 결과 비교. 센서 그림의 대각선은 수평·수직 화살표의 합성 방향과 길이에 맞췄다.

## 제작 기준

게이뤼삭 안내 그림을 스타일 참고 자료로 사용했다. 회청색 윤곽선, 단순한 도형, 적은 색과 짧은 표기로 구성하며, 보드의 3D 사진을 합성하지 않는다. 실험 구성은 [이전 실험](https://physics-lab-archive.notion.site/3b1a485802c48153bd1ed5ea2cd36ca3)을 참고했다. 해당 페이지의 사진·활동지는 복제하지 않았다.

최종 생성·수정 프롬프트는 [prompts.json](../../../dev/design/centripetal-guide/prompts.json)에 보관한다. 이 그림은 절차 안내용이며 실제 측정 자료나 센서 정확도 검증 결과가 아니다.
