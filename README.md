# Microbit Sensor Dashboard (마이크로비트 센서 대시보드)

마이크로비트(micro:bit)를 무선 센서로 활용하여, 실시간 데이터 측정값(카드 및 그래프)과 로그를 확인하고 분석용 CSV 파일로 다운로드할 수 있는 교육용 웹 대시보드입니다.

이 프로젝트는 수업 목적이나 사용하는 센서 종류에 따라 웹앱 화면에서 실험 설정을 바꾸고, 그 설정을 압축 URL이나 QR 코드로 공유할 수 있도록 구성한 정적 웹앱 템플릿입니다. 준비된 MakeCode 공유 프로젝트를 연결해 학생들이 바로 펌웨어를 열고 수정할 수 있는 흐름을 기준으로 합니다.

## 처음 사용하는 분께

### 준비물

- 마이크로비트 (micro:bit)
- 컴퓨터 연결용 USB 케이블
- 구글 크롬(Chrome) 또는 마이크로소프트 에지(Edge) 브라우저 (블루투스 무선 통신을 위해 필요합니다.)
- 메이크코드(MakeCode) 편집기

> [!NOTE]
> 이 웹앱은 브라우저의 무선 통신(Web Bluetooth) 기능을 사용합니다. 이 기능은 보안 정책상 주소가 `https://`로 시작하는 보안 웹사이트이거나 로컬 테스트용 주소인 `http://localhost`에서만 작동합니다. 학교 수업에서 여러 학생과 함께 사용하실 때는 무료로 웹 호스팅을 제공하는 GitHub Pages로 배포하여 사용하는 것을 권장합니다.

### 빠른 시작

1. **MakeCode 프로젝트 열기**: 웹앱의 **사용 안내**를 열고 **MakeCode에서 편집하기** 버튼을 눌러 준비된 micro:bit 프로젝트를 새 탭에서 엽니다.
2. **마이크로비트에 다운로드**: MakeCode에서 코드를 확인하거나 수정한 뒤 **Download** 버튼으로 프로그램 파일(`.hex`)을 받고, 마이크로비트에 복사(전송)합니다.
3. **웹앱 실행하기**: 로컬 컴퓨터에서 테스트할 때는 웹브라우저로 html 파일을 단순히 더블클릭해서 열지 말고, 아래 명령어를 실행하여 로컬 웹 서버를 구동해 접속해야 합니다.
   (파이썬이 설치되어 있는 경우 터미널에서 다음 명령어를 실행합니다.)

   ```powershell
   python -m http.server 8080
   ```

4. **웹앱 접속**: 브라우저 주소창에 `http://localhost:8080`을 입력하여 접속합니다.
5. **실험 설정 확인**: 기본 예제는 바로 쓸 수 있습니다. 다른 펌웨어를 올렸다면 상단 **실험 설정** 버튼을 눌러 시작 명령과 CSV 필드 순서를 펌웨어에 맞춥니다.
6. **기기 연결**: 화면의 **디바이스 연결** 버튼을 클릭한 뒤, 블루투스 기기 목록에서 `BBC micro:bit`를 선택하여 연결합니다.
7. **센서 보정 (캘리브레이션)**: 마이크로비트 LED 화면에 보정 안내(동그라미를 채우는 화면 등)가 나타나면, 기기를 모든 방향으로 천천히 기울여 보정을 완료합니다.
8. **실시간 데이터 확인**: 마이크로비트가 보내는 실시간 데이터가 대시보드의 카드, 그래프, 데이터 로그 표에 자동으로 업데이트됩니다.
9. **데이터 다운로드**: 수업 시간이나 연구용으로 분석할 기록이 필요하다면 화면 하단의 **CSV 다운로드** 버튼을 누르세요.

*(팁) 마이크로비트 기기가 당장 없더라도 화면 구성을 미리 테스트해 볼 수 있는 가상(Mock) 데이터 모드를 지원합니다.*

```text
http://localhost:8080/?mock=1
```

### MakeCode 공유 프로젝트 URL 설정

이 저장소를 수업용으로 배포하기 전에는 실제 MakeCode 공유 프로젝트 URL을 연결해 주세요.

1. MakeCode micro:bit 편집기에서 템플릿 프로젝트를 열고 코드가 제대로 실행되는지 확인합니다.
2. MakeCode의 공유 기능으로 프로젝트를 게시한 뒤 공유 URL을 복사합니다.
3. `js/makecode-share.js`의 `MAKECODE_SHARE_URL` 값을 복사한 URL로 바꿉니다.

MakeCode 공유 링크는 유지보수하기 쉽도록 `js/makecode-share.js`에만 따로 모아 두었습니다. 실제 배포 전에는 학생들이 열 수 있는 MakeCode 공유 URL인지 확인해 주세요.

### 모바일 및 브라우저 사용 안내

- **PC (Windows / macOS / Chromebook)**: 구글 크롬(Chrome)이나 마이크로소프트 에지(Edge) 브라우저 사용을 권장합니다.
- **안드로이드 (Android)**: 모바일 크롬(Chrome) 또는 삼성 인터넷 브라우저에서 동작합니다. (※ 블루투스 연결을 위해 스마트폰의 **블루투스**와 **위치 정보(GPS)** 권한이 모두 켜져 있어야 합니다.)
- **아이폰/아이패드 (iOS/iPadOS)**: 기본 사파리(Safari) 브라우저는 웹 블루투스 통신을 지원하지 않습니다. Web BLE 기능을 지원하는 전용 브라우저 앱(예: Bluefy 등)을 앱스토어에서 받아 사용해야 합니다.

### 자주 겪는 문제 해결 (FAQ)

- **연결 기기 목록에 마이크로비트가 보이지 않아요**: 마이크로비트에 전원 케이블이 잘 연결되어 있는지, 혹은 이미 다른 스마트폰이나 PC와 블루투스로 연결되어 있지 않은지 확인해 주세요.
- **연결하자마자 오류 메시지가 뜹니다**: 마이크로비트에 전용 프로그램 파일(`.hex`)이 정상적으로 다운로드되었는지 확인하고, 마이크로비트 뒷면의 리셋 버튼을 눌러 재부팅한 뒤 다시 연결해 보세요.
- **연결은 되었는데 데이터 값이 들어오지 않아요**: 센서가 보내는 데이터 형식이 잘못 되었을 수 있습니다. 마이크로비트가 숫자들을 전송하는지 확인하세요.
- **센서 측정값이 이상하거나 값이 튑니다**: 주변에 센서에 영향을 줄 만한 것들을 치워주시고, 마이크로비트의 리셋 버튼을 눌러 다시 진행해 주세요.
- **로컬에서 대시보드 창은 열리는데 연결 버튼이 반응하지 않아요**: index.html을 더블클릭해서 실행하는 것으로는 이 앱이 작동하지 않습니다. `빠른 시작` 방법을 다시 확인해주세요.

## 새 센서로 빠르게 바꾸기

값 목록만 바꾸는 간단한 프로젝트라면 핵심 규칙은 하나입니다.

> micro:bit가 보내는 값의 순서와 웹앱 **실험 설정**의 CSV 필드 순서를 같게 맞춘다.

예를 들어 micro:bit가 온도와 밝기를 다음처럼 보낸다면:

```text
24.1,128
```

웹앱 상단 **실험 설정**에서 필드를 같은 순서로 둡니다.

| CSV 키 | 화면 이름 | 단위 | 소수점 |
| --- | --- | --- | --- |
| `temperature` | 온도 | C | 1 |
| `light` | 밝기 |  | 0 |

설정을 적용하면 카드, 차트, 로그, CSV 다운로드가 새 필드 기준으로 즉시 바뀝니다. 설정 창의 **수업 공유** 영역에서는 압축 `cfg` 링크를 복사하거나 QR 코드로 표시할 수 있습니다. 펌웨어 쪽은 `firmware/template.js`를 복사해 `sendSample()`만 먼저 바꿔보는 흐름을 권장합니다.

## 포크해서 나만의 프로젝트 만들기

이 저장소는 단순 센서 교체뿐 아니라, 특정 수업·실험·전시·연구 주제에 맞춘 micro:bit 센서 웹앱의 출발점으로 사용할 수 있습니다.

포크한 뒤에는 보통 다음 순서로 작업하면 좋습니다.

1. 측정하려는 값과 사용 장면을 정합니다.
2. micro:bit 펌웨어에서 어떤 값을 어떤 주기로 보낼지 정합니다.
3. 웹앱의 **실험 설정**에서 필드, 단위, 색상, 기본 표시 항목을 맞춥니다.
4. 제목, 안내 문구, 사용 가이드, 필요하면 화면 레이아웃을 프로젝트 주제에 맞게 바꿉니다.
5. `?mock=1`로 웹 UI를 먼저 확인한 뒤 실제 micro:bit로 검증합니다.
6. GitHub Pages 같은 정적 호스팅에 배포합니다.

더 자세한 개발 흐름은 [포크 개발자 가이드](docs/forking-guide.md)를 참고하세요.

## 배포 전 확인

- `?mock=1`에서 카드, 차트, 로그, CSV 버튼이 정상 동작하는지 확인합니다.
- 실제 micro:bit 연결에서 첫 데이터가 들어오는지 확인합니다.
- 펌웨어 전송 순서와 **실험 설정**의 CSV 필드 순서가 같은지 확인합니다.
- **수업 공유**의 링크 복사와 QR 표시가 배포 주소에서 정상 동작하는지 확인합니다.
- 앱 안에서 여는 문서 링크와 GitHub Pages 배포 주소가 올바른지 확인합니다.

## 라이선스와 출처

이 프로젝트는 micro:bit 센서 수업과 특화 웹앱 개발에 재사용할 수 있는 오픈소스 템플릿을 목표로 합니다. 이 프로젝트는 자바실험실(javalap.org)의 영향을 받았습니다.

QR 코드 생성은 `vendor/qrcodegen.js`에 포함된 [Project Nayuki QR Code generator library](https://www.nayuki.io/page/qr-code-generator-library)를 사용합니다. 해당 라이브러리는 MIT 라이선스이며, 라이선스 전문은 vendored 파일 헤더에 포함되어 있습니다.
