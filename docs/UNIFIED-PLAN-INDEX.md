## 진행 상태

2026-10-29 사용자 실기기 확인을 받아 M6와 M8-2 P5를 완료 처리했습니다. 이번 측정·메모·분석 UX 개선도 반영했습니다. 작업 범위·선행 조건·완료 기준은 [기획 §10](unified-sensor-lab-plan.md#10-구현-단계)에서 관리합니다.

| 단계 | 상태 |
|---|---|
| M1 · 공통 측정·저장·분석 | 구현·검증 완료 |
| M2 · 센서·활동·장치 준비 | 사용자 실기기 검증 확인으로 완료 |
| M3 · 도구 링크·QR | 구현·배포 완료. 휴대폰 카메라 판독 등 검증 범위는 이력 참조 |
| M4 · 통합 인수 | 자동 검사와 사용자 최종 인수로 완료 |
| M5 · 도메인·배포 전환 | main 반영·공식 도메인 배포·포털 연결 검증 완료. 새 origin 실기기 인수 대기, 자동 배포 연결 보류. [배포 기록](m5-deployment.md) |
| M6 · 설치 경로 개선 | 구현·실기기 인수 상태는 [설치 개선 설계](sensor-program-installation-roadmap.md#84-현재-검증-결과와-남은-작업)에서 관리 |
| M7 · 교사 자료 공유 | 계획·미착수, M5 이후 |
| M8 · 센서·실험 확장 | M8-2 P1–P5 구현·검증·사용자 실기기 확인 완료. M8-1 새 센서·활동은 대상 미정 |

현재 운영 주소는 Cloudflare의 lab.sco.pe.kr입니다. M5는 2026-10-30 main 기준으로 배포했으며 센서 작업 브랜치 병합 후에도 최신 main을 같은 주소에 배포합니다. 앱 내부 Bluetooth 직접 설치는 M6-2로 진행하며 공식 모바일 앱을 거치는 설치 안내를 대체합니다.
