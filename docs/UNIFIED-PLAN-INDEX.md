## 진행 상태

2026-10-28 M8-2 P4 구현과 P5 자기장 실기기 핵심 흐름 확인을 반영했습니다. M6 정책은 2026-10-27, 다른 단계는 2026-10-26 기준입니다. 작업 범위·선행 조건·완료 기준은 [기획 §10](unified-sensor-lab-plan.md#10-구현-단계)에서 관리하고 이 문서에는 상태만 요약합니다.

| 단계 | 상태 |
|---|---|
| M1 · 공통 측정·저장·분석 | 구현·검증 완료 |
| M2 · 센서·활동·장치 준비 | 사용자 실기기 검증 확인으로 완료 |
| M3 · 도구 링크·QR | 구현·배포 완료. 휴대폰 카메라 판독 등 검증 범위는 이력 참조 |
| M4 · 통합 인수 | 자동 검사와 사용자 최종 인수로 완료 |
| M5 · 도메인·배포 전환 | 계획·미착수 |
| M6 · 설치 경로 개선 | M6-1 USB 도움말·파일 받기 구현·자동 검증, 파일 복사 실물 확인 남음. 부분 교체·자동 복구·안내 UI의 앱 통합 구현. 개발 B/C 실물 복구 확인, 정식 화면의 환경별 실물 인수 대기. [현재 개발 기준](sensor-program-installation-roadmap.md) |
| M7 · 교사 자료 공유 | 계획·미착수, M5 이후 |
| M8 · 센서·실험 확장 | M8-1 대상 미정. M8-2 P1–P4 자료·저장, 수동 측정, 연속 연계, 자료별 분석·점 CSV 구현·검증 완료. P5 통합 인수 미완료 |

현재 운영은 GitHub Pages입니다. 공식 주소로 정한 lab.sco.pe.kr의 연결은 M5에서 진행합니다. 앱 내부 Bluetooth 직접 설치는 M6-2로 진행하며 공식 모바일 앱을 거치는 설치 안내를 대체합니다.
