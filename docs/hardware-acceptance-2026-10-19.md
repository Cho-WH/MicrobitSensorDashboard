사용자가 준비한 micro:bit V2 한 대를 localhost 통합 실험실에서 검사했다.
`mock` 매개변수가 없는 실제 장치 화면을 사용하고, 사용자가 USB·Bluetooth 선택창에서
장치를 선택했다. USB 설치기는 보드 V2 확인과 고정 HEX 해시 검사를 통과해야 전송한다.
앱에 저장되는 실측 기록과 이전 모의 검사를 구분한다.

## 확인된 결론

새 세 센서의 **실물 한 대에서 USB 설치 → BLE 수신 → 기록 → 저장 → 분석·재열기**
기본 경로는 통과했다. 조도는 명시적 BLE 해제·같은 장치 재연결·일시정지 기록 재개까지
확인했다. 관측된 수신 간격은 온도 약 1.05초, 조도·가속도 약 0.15초다. 펌웨어의 명목
대기 설정 1초·0.1초를 실측 수신 주기로 표현해서는 안 된다.

## 아직 확인하지 않은 범위

표준 계측기 대비 정확도, 여러 보드·운영체제·브라우저, 장시간 수신·배터리 단독 동작,
설치 중 USB 분리·취소·오류 복구는 별도 확인 대상이다. 재연결은 조도의 앱 연결 해제와
같은 장치 재연결 경로만 확인했으며 전원 손실이나 전파 단절에 의한 자동 복구는 미확인이다.
실측 파일 다운로드와 재가져오기는 아직 검증하지 않았다. 앞선 모의 데이터의 파일
왕복 검사를 이번 실측 파일 검증으로 대신 보고하지 않는다.
전체 인수 완료를 뜻하는 `hardwareVerified`는 아직 변경하지 않는다.
