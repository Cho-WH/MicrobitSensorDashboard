## 1. 목표

외장 자기장 MLX90393의 작은 변화/강한 자석 프리셋과 기록 이후 설정 유지 흐름은 [MLX90393 설계](mlx90393-design.md)에 정의한다. 기존 공통 준비·측정·분석 화면을 사용한다.

센서를 선택하면 맞춤 펌웨어·배선·측정 항목·그래프가 준비되고, 실험 활동을 선택하면 탐구 절차·기록 버튼·분석 제안이 추가되는 하나의 앱을 만든다. **공통 구조는 게이뤼삭 앱의 준비→USB 프로그램 전송→BLE 수신 확인→측정·자동 저장→학생 주도 분석→근거·해석 기록을 기준으로 한다.** 기본 공유는 도구를 바로 여는 링크 복사와 QR 생성으로 한정한다. 교사의 실험 JSON을 바탕으로 수업 자료를 배포하는 기능은 후순위로 분리한다.

기본 원칙은 센서가 측정 가능 범위를 결정하고, 활동이 탐구 맥락을 결정하며, 도구 링크가 그 도구의 진입점을 전달하는 것이다. 공유를 위해 별도의 수업 설정을 작성하게 하지 않는다. 분석 구간·축·계산·자료 제외·해석의 판단은 학생에게 남긴다.

**범위:** 이 저장소에 센서 측정·특화 실험 활동을 모두 담는 **단일 센서 실험 앱**을 구축한다. 센서마다 또는 게이뤼삭 같은 활동마다 별도 앱·저장소를 만들지 않는다. 이 문서는 앱 내부의 탐색, 준비·측정·분석, 데이터·상태, 도구 공유와 후속 자료 공유의 경계를 정의한다. 앱의 공식 도메인 연결·기존 주소 전환과 Cloudflare 공유 저장소 연계를 포함한다. 상위 포털은 앱 소개·실행 링크의 연결 경계만 다루며, 포털 자체 기능과 다른 교육 도구의 이전은 범위 밖이다.

## 3. 시작 화면과 진입 경로

### 3.1. 앱 홈

이 앱의 첫 화면은 **센서로 측정하기**와 **실험 활동 시작하기**를 동등한 선택지로 제공한다. 센서를 먼저 고르지 않아도 활동을 바로 선택할 수 있고, 센서를 선택한 뒤에는 그 센서를 사용하는 추천 활동으로 이어질 수 있다. 처음 사용자에게는 센서 카드와 활동 카드의 목적을 간결하게 안내한다.

센서 카드에는 측정 제목·사용 센서·짧은 행동 안내와 현재 제공하는 관련 활동을 표시한다. 관련 활동이 많으면 오버레이로 펼쳐 선택한다. 활동 카드에는 직관적인 탐구 제목·정식 실험명·설명·사용 센서·검증된 교육과정 연결을 표시한다. 어느 경로든 선택 시 미리보기로 이동하며 장치 연결이나 기록을 시작하지 않는다.

이 앱에 저장된 실험 이어하기와 실험 파일 열기도 같은 첫 화면에서 제공한다. 앱의 홈은 센서·활동 탐색만 담당하며, 준비·측정·분석 기능을 별도 앱으로 분산시키지 않는다.

실시간 Bluetooth 측정이 지원되지 않는 환경에서는 권한 요청이나 팝업 없이 홈·실험 소개·준비·측정 화면에 공통 안내를 표시한다. HTTPS 접속 문제와 페이지 접근 제한은 브라우저 미지원과 구분한다. 준비 안내 열람과 파일 분석은 유지하고, 분석·저장 목록에서는 연결 안내를 반복하지 않는다. iPhone·iPad의 미지원 브라우저에는 Bluefy App Store 링크와 현재 주소 복사를 제공하고, 앱 설치 후 복사한 주소로 다시 접속하도록 안내한다. 복사가 거부되면 직접 선택할 수 있는 주소를 보여 준다. 카드 안에는 파일 열기 버튼을 중복 배치하지 않으며, 이 실험실과의 실물 연결 미검증 및 센서 프로그램의 별도 설치 필요성을 도움말에 명시한다.

### 3.2. 선택 이후의 경험

**센서로 측정하기:** 센서 카드에서 BMP280 또는 내장 자기장 등을 선택한다. 펌웨어·배선·측정값·단위·기본 그래프를 자동 준비하고 자유 측정으로 이어진다. 활동 선택은 필수가 아니다.

**실험 활동 시작하기:** 게이뤼삭 실험 등을 선택하면 호환 센서와 준비물, 용기·수조 안내, 활동 전용 조작 기록과 분석 제안을 함께 연다. BMP280 자유 측정과 게이뤼삭 활동은 동일한 펌웨어와 분석 엔진을 사용할 수 있다.

**도구 링크로 시작하기(M3):** 도구 미리보기에서 제공하는 링크와 QR은 보고 있는 센서·활동의 실험 소개 화면을 연다. 학생이 **처음부터 준비하기 / 이미 준비했어요**을 선택한 뒤 자신의 장치를 연결하고 기록한다. 링크를 열거나 다시 방문하는 것만으로 기록을 만들거나 기존 기록을 초기화하지 않는다. 이전 기록은 저장된 실험에서 명시적으로 이어간다.

선택 후에는 상단에 **BMP280 · 온도와 기압 측정** 또는 **기체의 온도와 압력**처럼 현재 센서·활동 이름과 준비·측정·분석 흐름을 표시한다. 모든 경로는 같은 UI와 엔진을 사용하되, 해당 탐구에 필요한 항목만 보여 준다. 전체 센서·활동 목록은 홈으로 돌아갈 때 열고, 센서 준비 화면에는 그 센서로 할 수 있는 활동을 선택적으로 안내한다.

### 3.3. 탐색·전환과 실험 보존

- 카드·도구 주소·실험 소개를 여는 것만으로 측정 Run을 만들지 않는다. 준비 설정은 시작 구성으로 유지하고, 새 측정 Run은 최초 **기록 시작** 때 생성한다. 이어하기는 기존 Run을 열고, 파일 가져오기는 파일의 실험을 복원한다. 후속 공유 자료의 학생 사본은 별도의 **내 분석 시작** 동작으로 만든다.
- 상단 **자료 분석** 탭은 실제 기록이 생긴 뒤 활성화한다. 첫 기록 시 탭이 화면에 보일 때만 한 번 강조하고, 저장 자료 열기에는 효과를 생략한다. 기록 중에도 분석으로 이동할 수 있으며 기록은 계속된다. 기록 종료 후 **기록 마치기** 자리는 **자료 분석하기**로 교체한다. 활동별 중복 이동 버튼은 두지 않는다. [공통 표시 규약](design/visual-language.md#측정에서-분석으로-이동)을 따른다.
- 같은 실험실의 준비·측정·분석 화면을 오갈 때는 구성·기록을 유지한다. **실험 선택**, **새 실험 준비** 또는 다른 도구로 나갈 때는 **현재 도구 사용을 마칠까요?** 확인창을 표시한다. **취소**하면 현재 사용을 계속하고, **종료하고 이동**하면 분석 초안과 기록을 마감·저장한 뒤 목적지 페이지를 새로 불러온다. 이전 페이지의 장치 연결은 문서 종료로 정리한다. 저장 실패 시 현재 화면·실험·연결을 유지하며 재시도할 수 있다. 임시 분석처럼 브라우저에 저장할 수 없는 자료는 같은 확인창에서 파일로 보관하고 이동하거나 취소한다.
- 선택 화면에는 활성 실험이 없다. 카드를 열면 미리보기부터 선택한 실험의 이름을 상단에 표시한다. 미리보기는 안내만 제공하며 장치 연결·기록 권한은 **처음부터 준비하기** 또는 **이미 준비했어요**을 누른 뒤 열린다. 같은 센서의 다른 활동도 종료한 실험의 연결·준비 확인을 자동 상속하지 않는다. 이전 기록은 저장된 실험에서 명시적으로 열어 이어간다.
- 미리보기 주소는 센서·활동 경로에 `?view=preview`를 붙여 구분한다. 새로고침·뒤로 가기·앞으로 가기에서도 미리보기 소속을 유지한다. 이력 이동으로 현재 실험실을 벗어날 때도 동일한 저장·연결 종료 규칙을 적용하며 실패하면 현재 실험의 주소로 복구한다. 기존 센서·활동 직접 준비 주소는 유지한다.
- 브라우저의 다른 사이트로 이동하거나 현재 앱을 닫는 것은 센서 앱을 떠나는 동작이다. 기록 중이거나 분석 글 등 미저장 변경이 있으면 기록을 마치고 저장한 뒤 이동하거나 현재 실험에 머물 수 있게 한다. 주 버튼은 상태에 맞게 **기록을 마치고 이동** 또는 **저장하고 이동**으로 표시한다. 저장 실패는 재시도·파일 보관으로 해결하고, 앱을 떠나도 기록이 계속된다고 안내하지 않는다.

## 4. 센서·활동 설정과 공유의 경계

| 구분 | 포함 정보 |
|---|---|
| 센서 정의 | ID·버전, 지원 micro:bit와 모듈, 배선, 펌웨어 파일·해시, 통신 프로토콜, 측정 채널·단위·유효성, 보정, 기본 표시 |
| 활동 정의 | ID·버전, 호환 센서, 준비물, 진행 단계, 전용 사건·버튼, 기본 분석 제안, 탐구 질문 |
| 도구 공유(M3) | 현재 미리보기 중인 센서·활동의 실험 소개 주소. 별도 수업 구성 없음 |
| 교사 자료 공유(후순위) | 검증된 실험 JSON에서 만든 자료 사본, 수업 제목·질문·안내, 공유 식별자와 만료일 |

도구 진입의 적용 순서는 **센서의 지원 범위 → 활동의 필수 조건과 기본값 → 학생의 분석 선택**이다. 링크는 교사의 표시 채널·축·회귀·계산식이나 장치 설정을 전달하지 않는다. 후속 자료 공유도 파일에 없는 채널·측정 명령을 만들거나 학생에게 장치 권한을 넘기지 않는다.

실험에는 적용된 센서·프로그램·활동의 버전과 사본을 보관한다. 기록이 있는 실험의 센서·활동은 유지하며, 다른 구성으로 시작하는 동작은 §3.3을 따른다. 기존 실험 이어하기는 당시 보관한 구성을 사용한다. 도구 링크는 현재 제공 중인 도구를 여는 주소이며 과거 화면·정의 버전을 고정하는 자료 보관 링크가 아니다. 후속 교사 자료 공유의 사본·출처 보존은 §8에서 별도로 정한다.

### 센서·활동 둘러보기

센서·활동 소개의 **둘러보기**는 같은 도구의 `?mock=1&view=prepare`로 진입하여 장치 준비 첫 단계부터 시작한다. 별도 체험 페이지를 만들지 않는다. 버튼 안의 물음표 도움말은 기기나 실험 환경 없이 전체 기능을 모의로 체험할 수 있음을 안내한다. USB·무선 설치는 기존 설치 화면에서 예시 장치 선택·진행률·완료·취소·재시도를 모의로 제공하며 실제 USB·Bluetooth 권한은 요청하지 않는다. 공통 장치 선택창에서 예시 micro:bit 선택 → 연결 대기 → 새 값 수신 확인을 거친 뒤 사용자가 기록을 시작한다. 최상단 제목 옆의 옅은 **둘러보기 상태**로 구분하며 측정 본문에 모의 자료 안내·출처·가공 설명을 추가하지 않는다.

일반 센서별 예시 신호를 약 1분 분량으로 미리 구성하고, 기록 시작 시 첫 표본부터 센서의 수집 간격대로 재생한다. 일시정지·재연결 중에는 기록용 재생 위치를 유지한다. 마지막 표본이 기록된 뒤 공통 기록 마침을 실행하고 자료 분석하기 버튼을 제공한다. 미리보기는 반복해 볼 수 있으며 새 실험·추가 측정에서는 다시 첫 표본부터 시작한다. 원자료·계산·분석 UI와 기록의 유효성 검사는 실제 측정과 동일하다.

구심가속도와 게이뤼삭 활동은 각각 약 3분의 예시를 재생한다. 구심가속도는 시작·가속, 주기 1.5초의 일정한 회전, 더 빠른 주기 0.95초의 회전, 감속·정지로 구성한다. 측정 화면 진입 즉시 반지름 20cm(0.2m)를 입력하고 예시 조건으로 고정한다. 학생의 회전수·구심가속도 계산과 분석 답변은 대신 채우지 않는다. 게이뤼삭은 실제 1차 측정의 온도·압력 쌍을 보존하며 시간을 압축한다. 물 추가와 병 넘어짐 메모를 재생 위치에 맞춰 자동 기록하고, 공통 실험 메모·그래프·파일에 남긴다. 이 자동 메모는 게이뤼삭 둘러보기에만 적용하며 미리보기·일시정지 중에는 발생하지 않는다. 추가 측정에서는 새 재생에 맞춰 다시 기록한다.

체험 기록은 현재 문서의 메모리에만 보관하고 실제 저장된 실험 및 복원 정보를 변경하지 않는다. 새로고침하면 초기화되며, 기록이 있는 상태에서 둘러보기를 종료할 때 이를 안내한다. JSON·CSV 내보내기는 기존 모의 출처를 보존한다. 일반 파일 열기는 둘러보기 종료 후 사용한다. **둘러보기 종료**는 같은 도구의 일반 소개로 돌아가며 실제 연결·기록을 자동 시작하지 않는다. 모바일 둘러보기에서는 상단의 파일 열기 자리에 종료 버튼을 두어 준비·측정·분석 단계에서 항상 사용할 수 있게 한다. 일반 모드의 모바일 배치는 유지한다.

## 5. 장치 준비 UX

자기장 보정 중에는 기존 micro:bit 3D 모델로 LED 면을 위로 두고 제자리에서 천천히 앞뒤·좌우로 기울이는 자동 시범을 보여 준다. 기울인 쪽의 LED가 밝아지고 지나간 칸은 켜진 채 남는다. 화면을 채우면 잠시 유지한 뒤 불을 끄고 다시 시작하는 약 16초 주기다. 고정 카메라·수평 기준면·그림자·동작 방향 화살표를 사용한다. 움직임 줄이기 설정에서도 재생하되 화면 밖이나 숨겨진 탭에서는 멈춘다. 3D를 사용할 수 없으면 같은 시작 자세의 정지 그림을 제공한다. **영상으로 보기**는 [공식 보정 안내](https://support.microbit.org/support/solutions/articles/19000008874-calibrating-the-micro-bit-compass)의 영상으로 연결한다. 점등은 동작을 설명하는 시범이며 실제 장치의 보정 진행률이나 완료를 뜻하지 않는다.

내장 센서의 준비물은 micro:bit V2 앞·뒷면, USB 연결, AAA 전지 2개 케이스를 정지 그림으로 보여 준다.
USB 설치 안내와 펼쳐 보는 배터리 전원 안내도 같은 그림을 사용한다. 준비 화면에서 3D 조작은 요구하지 않는다.
BMP280·DS18B20도 준비물·프로그램 단계에서 같은 카드와 본체·USB 그림을 쓰며, 센서·확장 보드·연결선·터미널 모듈은 공통 모델의 정지 그림으로 보완한다. 배선 단계에서만 공통 3D를 불러오며, DS18B20은 개별 점퍼선 연결로 고정하고 프로브 1~2개를 선택해 볼 수 있다. 보기 선택은 실제 장치 연결이나 준비 완료를 바꾸지 않는다.

게이뤼삭의 단계별 안내를 재사용하되 센서·활동에 필요하지 않은 단계는 생략한다. 내장 자기장은 외장 배선 단계 없이 펌웨어·보정·수신 확인으로 진행한다. 연결 후 앱에서 보정 시작 또는 이번 보정 생략을 선택한다. 보드는 이번 부팅 중 완료한 보정을 연결이 끊겨도 기억하며, 재연결 시 완료 응답을 받으면 보정 선택을 반복하지 않고 수신 확인으로 이어간다. 전원 차단·리셋 후에는 다시 선택한다. 보정 중 재연결에 응답이 없으면 보정을 완료하고 재연결하도록 안내한다. 보정 중에는 숫자 대신 보드 움직임 안내를 보여 주고, 장치의 완료·생략 응답 뒤 수신 확인으로 자동 전환한다. 보정 동작 시범은 움직임 줄이기 설정과 관계없이 자동 재생한다. 생략은 보정 완료로 표시하지 않고 기록 시작의 준비 이력에 남긴다. BMP280는 배선 안내를 추가한다. 게이뤼삭은 용기·수조 준비, 무선 수신과 배터리 확인을 더한다.

**M2 재점검 결정:** 원본의 큰 단계/세부 단계 탐색, 시각 자료와 설명의 병렬 배치, 이전/행동 버튼, 준비물 도움말을 보존한다. 배선·USB·수신·용기에 맞는 자료를 보여 주며, 준비 항목의 체크는 측정 진입을 막지 않는다. 현재 장치의 정상 연속 수신이 확인되면 측정 화면으로 이동하고 기록을 시작할 수 있다. 필수 준비와 이후 확인 단계가 모두 끝났으면 연결·수신 화면에서 중복된 ‘다음’을 숨기고 ‘측정 화면으로’를 제공한다. 보정·배터리·활동 안내와 확인 이력은 유지하며 수신 성공만으로 완료 처리하지 않는다. 게이뤼삭의 배치 그림과 실험 방법 안내를 복원하고 대시보드의 표시 채널 선택을 측정 화면에 적용한다. 표시 선택은 원자료 수집을 바꾸지 않는다. 당시 채택·제외 이유와 검증 근거는 [M2 인수 기록](history/m2-implementation.md)에 보존한다.

센서별로 사전에 검증한 HEX 파일을 제공하고, 게이뤼삭의 공식 USB 전송 어댑터를 재사용한다. 최초 브라우저 장치 선택·권한 부여는 유지한다. 설치 성공, BLE 연결 성공, 실제 측정값 확인을 구분한다. 프로그램 식별 정보를 확인할 수 없으면 이전 설치 이력이나 숫자 CSV만으로 설치 버전을 확정하지 않는다.

**M6 설치 UX 구현·사용자 실기기 인수 완료(2026-10-29):** USB 설치가 기본이며 같은 프로그램 단계에서 센서 실험실의 다른 프로그램을 USB 없이 교체할 수 있다고 안내한다. **무선으로 설치하기 / USB로 설치하기** 글자 링크로 방식만 전환한다. 완료 뒤 기존 연결·새 수신·보정 흐름을 계속한다. 재연결은 즉시 시도 + 실패 후 2초·4초·8초 대기이며 모두 실패하면 **“micro:bit 뒤쪽의 리셋 버튼을 한 번 누른 뒤 다시 시도해 주세요.”**와 **[다시 시도] / [USB로 설치하기]**를 제공한다. 성공한 전송을 반복하지 않고 비호환·전송 중단에는 USB를 안내한다. 학생 안내는 전원·거리·장치 선택 등 필요한 행동만 설명한다. M6-1은 USB 설치 도움말 안의 문제별 안내·검증된 HEX 파일 받기로 구현했다. 다운로드는 설치 완료로 처리하지 않는다. 상세 상태·문구·재진입은 [설치·연결 설계 §3](sensor-program-installation-roadmap.md#3-설치-화면과-사용자-흐름)을 따른다.

일반 사용자에게 MakeCode 코드나 CSV 열 순서를 맞추게 하지 않는다. 사용자 정의 펌웨어와 임의 센서 조합은 고급·후속 경로로 둔다.

**교실 기기 식별 — 정식 V1 구현, 실물 확인 대기:** 연결 대기 중 보드에 앱 아이콘(네 모서리 프레임과 중앙 십자)과 다섯 글자 기기 이름을 번갈아 표시한다. 연결 후 시작 요청 전에는 화면을 비우며, 측정값 송신 중에는 파형이 위아래로 움직인다. 조도 측정 중에는 비우고 설치·보정 화면은 우선한다. 앱에서는 같은 이름의 기기를 고르도록 안내한다. 동작 범위와 확인 기준은 [센서 프로그램 공통 동작 규약](sensor-program-contract.md#5-기기-식별과-측정-표시)을 따른다. 이름·패턴 입력이나 추가 실물 확인 단계는 이번 범위에 포함하지 않는다.

움직임 줄이기 설정에서도 버튼의 유리 배경·테두리·눌림 색상, 키보드 초점·선택 단계 강조, 설치 진행률·성공·오류 표시는 유지한다. USB·무선 설치 방식 전환 시 설명·설치 카드·장치 그림에 짧은 전환 효과를 적용하되, 움직임 줄이기 설정에서는 즉시 바뀐다.

## 6. 측정·저장 계약

내장 센서의 측정 화면에 처음 들어가면 공통 실험 안내 팝업으로 센서 위치와 측정 시 알아둘 점을 보여 준다. 온도는 메인 프로세서, 자기장·가속도는 통합 칩을 뒷면 3D 캡처에 표시하며, 밝기는 빛을 감지하는 앞면 LED 배열을 표시한다. 같은 페이지에서 이미 본 안내는 자동으로 반복하지 않고, 측정 화면의 ‘센서 위치 보기’로 다시 열 수 있다. ‘이 안내 자동으로 열지 않기’ 설정은 센서별로 보관한다. 가져온 자료에는 자동으로 열지 않으며 안내 표시가 기록 상태를 바꾸지 않는다.

장치 연결 후 수신값은 **준비용 미리보기**로 사용한다. 사용자가 **기록 시작**을 누른 뒤부터 측정값을 원자료로 보관한다. 게이뤼삭에서는 기록 시작 후 가열 전 기준 자료를 관찰하고, 별도의 **가열 시작** 사건을 남긴다.

측정 화면은 연결·기록 상태를 장치 카드 안에서 같은 크기의 상태 점과 글자로 나란히 표시하고, 연결 도움말은 장치·실험 설정에서 제공한다. 두 측정 탭 모두 데스크톱 조작부는 최대 두 줄로 배치한다. 기록 중 첫째 줄은 한 점 기록·일시정지(또는 재개), 둘째 줄은 기록 마치기·새 실험이다. 시작 전에는 설정에 맞는 시작 버튼만 표시하고, 종료 후에는 첫째 줄에 추가 측정, 둘째 줄에 새 실험을 전체 너비로 제공한다. 모바일은 표시되는 모든 버튼을 같은 너비의 한 줄로 배치하며, 좁은 화면에서는 버튼 내부 문구의 줄바꿈을 허용한다. 새 실험도 공통 보조 버튼의 높이·글자 크기를 사용한다. 일시정지 중에는 한 점 기록을 제자리에 비활성으로 유지한다. 재연결은 주 행동 자리를 대신하며 기록 중 재연결을 누르면 일시정지한 뒤 연결하고, 명시적인 재개를 기다린다. 작은 화면은 상태 한 줄 아래에 같은 높이의 버튼들을 배치하고, 그 아래에 실시간 숫자와 그래프를 둔다. 기록 시작 전에는 기록 개수를 생략한다. 그래프 제목 옆의 공통 드롭다운에서 최근 60초·전체 범위를 선택하며, 채널 범례와 표시 단위는 다음 줄에 둔다. 표시 범위·단위 변경은 원자료 수집·보관에 영향을 주지 않는다.

두 측정 방식의 탭 아래 공통 안내줄에는 저장 관련 안내와 모의 장치 안내만 표시한다. 안내문이 있을 때만 각진 얇은 줄로 나타나며, 개수만 남거나 빈 높이를 차지하지 않는다. 시작·재개·마침·처리 중·수신 대기·편집 완료 등의 반복 안내는 생략한다. 한 점 기록 완료는 표가 접혀 있을 때 펼치기 버튼에 잠깐 표시하고, 펼치면 기록 개수로 돌아간다. 실제 조작 실패는 기존 공통 오류 영역에서, 셀 입력 오류와 그래프의 수신 시각은 해당 자료 옆에서 제공한다.

측정 화면은 현재 값·단위, 수신/기록/저장 상태, 시간 그래프, 일시정지·재개·기록 마치기, 실험 메모를 제공한다. 활동은 물 추가·장치 변경 같은 메모 빠른 입력 버튼을 추가한다. 게이뤼삭 활동의 측정 화면에서는 용기 배치 확인·가열 시작 버튼과 선행 순서 제한을 제거하고, 물을 더한 시점은 **물 추가**로 기록한다. 준비 단계의 배치 안내는 유지하되, 폐기한 측정 조작의 정의와 레거시 호환 처리는 남기지 않는다. 수신이 끊겨도 기존 자료를 보존하고 시간 공백을 기록한다. 값이 일정하다는 이유만으로 단절을 판단하지 않는다.

가속도는 앱에서 m/s²로 환산해 기록한다. 측정·기록 화면의 **g로 보기** 토글은 실시간 숫자와 그래프 축의 표시만 바꾸며, 저장·분석·내보내기 단위는 m/s²를 유지한다. 중력을 포함하므로 정지 상태의 크기는 약 9.8m/s²(약 1g)다. 기존 mg 기록은 원래 단위로 열어 분석하고, 새 측정은 새 실험으로 시작해 서로 다른 단위가 섞이지 않게 한다.

시간 그래프는 세로축별 기본 범위를 유지하여 작은 변화를 과장하지 않는다. 기본 범위는 전체 기록과 센서 기준값을 포함하고 필요할 때만 넓어진다. 최근/전체/선택 구간 전환은 기본 세로축을 좁히지 않는다. 각 축 위의 ＋ 돋보기로 현재 보이는 값에 맞춰 확대하고, 같은 자리의 − 돋보기로 복원한다. 아이콘의 도움말과 접근성 이름에 대상 축과 행동을 표시한다. 확대 상태는 단위·표시 항목 변경과 재렌더에서 유지하며 새 실험에서는 초기화한다. 측정·원자료·활동의 시간 그래프가 같은 동작을 사용하고, 관계 그래프는 기존 범위 정책을 유지한다. 기본값의 등록 계약은 [모듈 등록 안내](../src/catalog/README.md#시간-그래프의-공통-축)에 따른다.

**화면 전환과 측정 세션 수명을 분리한다.** 분석으로 이동해도 측정·저장이 계속된다. 계속 수신되는 연속 자료는 '새 자료 반영'으로 가져오고, 점 기록·편집 확정·취소·복원은 자동 반영한다. 기록 일시정지는 새 측정값을 저장하지 않으며, 기록 마치기는 대기 중인 연속 자료도 분석에 반영한다. 지정 범위·제외·보관 근거·해석은 유지한다. 새로고침 복원은 자동 장치 재연결이나 기록 재시작을 의미하지 않는다.

같은 탭에서 새로고침하면 직전에 열었던 저장 실험과 화면을 별도 완료 안내 없이 복원한다. 전체 저장 목록의 최신 실험을 임의로 열지 않는다. 측정 화면에서는 기존 기록 시작·재개 버튼 자리에 `장치 다시 연결`을 표시한다. 이전 장치 권한을 재사용할 수 있으면 직접 연결하고, 사용할 수 없으면 같은 버튼으로 장치 선택창을 연다. 새 수신 확인 후 기존 기록 버튼으로 돌아오며, 연속 기록 재개는 사용자가 선택한다.

RunStore를 원자료·사건·분석 작업·미저장 변경의 단일 소유자로 사용한다. 표시용 그래프 버퍼의 상한과 원자료 보존량을 분리하고, 저장 실패·재시도·한 탭 작성 권한·읽기 전용 복원을 계승한다.

저장된 실험 목록에서 이름 변경과 삭제를 제공한다. 삭제는 대상 이름과 삭제 범위를 확인한 뒤 수행하며,
다른 탭의 작성 잠금이나 저장 실패를 우회하지 않는다.

두 측정 탭은 같은 **실험 메모** 표를 사용한다. 표는 시각·메모·옵션으로 구성하며 한 점 기록표의 공통 표·스크롤·버블 편집을 재사용한다. 기록 중과 일시정지 중 **+ 메모**로 새 메모를 열고, 활동 버튼은 같은 입력창에 내용을 미리 채운다. 시각은 입력창을 연 순간에 고정한다. 입력창을 떠나면 자동 확정하고, 내용 비우기와 기록 취소·복구를 구분한다. 종료 후에도 기존 메모를 수정·비우거나 취소·복구할 수 있다. 취소는 내용과 시각을 보존하며 그래프 표식에서 제외한다. 연결·수신 변화와 기록 시작·정지 등의 이력은 **장치·실험 설정 → 연결·기록 이력**의 접힌 목록에 둔다.

측정 그래프의 메모 표찰은 시간축 아래에 표시하고 해당 시점의 세로 점선을 유지한다. 표찰 하나는 해당 메모 편집으로 연결하고, 가까운 표찰은 묶어 목록을 연다. 현재 표시 범위에 유효한 메모가 없으면 표찰 공간을 두지 않는다.
추가 측정에서는 같은 센서·프로그램·활동 사용을 확인하고 용기·부피, 밀폐, 센서·배선·설정의 변경 없음/변경됨/불확실을
각각 남긴다. 변경 또는 불확실한 조건이 있으면 메모를 필수로 받는다.

원본 앱에서 저장한 전체 실험 JSON도 현재 앱에서 분석하고 이어 측정한다. 실제 장치 출처와 등록된 센서·활동·펌웨어·채널 규약이
맞는 파일만 장치 연결을 허용하며, 열기만으로 연결하거나 기록하지 않는다. 사용자가 연결과 수신 확인을 마친 뒤 기록 재개 또는
추가 측정을 선택한다. CSV·출처 불명 파일·호환되지 않는 구성·임시 분석은 분석용으로 유지한다.

**M8-2 P1–P3 구현:** 측정 화면 안에서 **연속 측정 / 한 점씩 측정**을 선택한다. 수동 전용은 실시간 계기·조건 입력·기록 버튼·편집 표를 함께 제공하고 첫 유효 점 기록 때 Run을 만든다. 연속 기록 중에도 **한 점 기록**으로 현재 원자료에 조건값을 연결하며 연속 저장을 유지한다. 기록 방식은 Run 생성 후 유지하고, 상세 UX·캡처 상태·자료 보존은 [한 점 기록·연속 연계 설계](point-recording-design.md)를 따른다.

**2026-10-29 변경 구현:** 측정 탭은 화면 배치로 분리해 기록 중에도 이동할 수 있게 한다. 탭 옆 **연속 기록** 토글이 연속 저장 여부를 정하며, 시작 전 탭 이동은 연속 화면 ON·한 점 화면 OFF를 기본 적용하고 수동 변경도 허용한다. ON은 기록 시작 후 한 점 캡처, OFF는 첫 점으로 시작한다. 첫 Run 생성부터 종료·추가 측정까지 토글을 고정한다. 두 화면의 캡처와 일시정지·재개를 통일하며, 일시정지는 저장뿐 아니라 숫자·계기·시간 그래프도 멈춘다. OFF의 시간 그래프는 저장 자료와 분리한 최근 60초 메모리 미리보기이고 전체 보기는 비활성화한다. 버퍼는 수신 빈도에 맞춰 실제 60초를 보관한다. 기존 구현 설명과 구별하며 변경된 사용 흐름·도움말·검증 기준은 [상세 설계 §3](point-recording-design.md#3-정보-구조와-화면-이동)·[§6](point-recording-design.md#6-실시간-계기의-표시-계약)·§15.3을 따른다.

같은 날 UX 검토에서 토글 명칭을 **연속 기록**으로 확정했다. 시작 전 탭 이동이 수동 설정보다 우선하는 규칙은 유지한다. 어느 화면에서도 실제 기록 상태·일시정지를 확인할 수 있게 하고, 시작 전 주 행동은 ON의 기록 시작/OFF의 한 점 기록으로 구분한다. 고정된 숫자에는 일시정지 상태, OFF 그래프에는 최근 60초·저장 안 함을 표시한다. 배치·접근성·표시 위계는 상세 설계 §3.2에서 관리한다.

조작부의 **새 실험**을 선택하면 같은 센서·프로그램·활동에서 기존 기록을 마감·저장하고 현재 측정 탭·연속 기록 설정·유효한 연결·준비 상태를 유지한다. 연속 기록 설정은 자동 반전하지 않으며 새 실험의 첫 기록 전 다시 선택할 수 있다. 새 실험은 사용자의 기록 조작으로 시작하며 이전 수신값을 가져오지 않는다. 연결이 끊겼거나 준비가 필요하면 장비 준비로 안내한다.

## 7. 공통 분석과 활동별 지원

게이뤼삭의 **원 자료 보기 → 관계 그래프 → 결과 해석**을 모든 센서에 적용한다. 표·필터·구간 선택·제외와 사유·계산 열·축 선택·산점도·시간 그래프·회귀·추세선 연장·근거 보관·해석 글을 재사용한다. 활동은 권장 축·계산 예시·질문을 제공하지만 학생의 결론을 자동 입력하지 않는다.

**구심가속도 활동(작업 브랜치 구현):** 공통 원자료·저장 기능을 유지하면서 기록·분석 본문을 학습 활동에 맞게 구성했다. 측정 그래프에서 기록한 A/B 구간을 두 계산 과정에 함께 사용한다. 구간 선택과 가속도 센서·주기의 두 계산 열을 한 화면에 두고 결과 비교만 분리한다. 그래프는 직접 접을 수 있고 넓은 데스크톱에서는 오른쪽에 가속도 측정·주기 측정을 같은 폭으로 쌓는다. 중간 화면에서는 두 카드를 나란히, 작은 화면에서는 세로로 놓는다. 평균 구하기·주기 적용 버튼은 결과칸과 같은 줄에 두며 적용 상태 안내 영역은 생략한다. 성분 벡터는 중력 길이를 고정하고 센서 평균에 따라 비율·각도를 갱신한다. 원운동 개념도는 형태를 유지하고 학생 입력을 숫자로 연결한다. 가속도 측정은 선택 구간과 평균 결과칸·평균 구하기 버튼을, 주기 측정은 걸린 시간 ÷ 회전수 = 주기를 제공한다. 두 측정값이 준비되면 분석을 자동으로 펼치고 조건이 무효가 되면 입력을 보존한 채 접어 비활성화한다. 원자료 표는 최하단에 두고 선택 이유 입력칸은 생략한다. 주기는 명시적 적용으로 입력하며 가속도 평균은 버튼을 눌러 확인한다. 두 계산 열의 도움은 관계식·대입 과정까지만 제공하고 자동 계산 답은 제공하지 않는다. 학생 입력·재확인·고정한 근거와 출력을 보존하며 일반 센서의 그래프 중심 분석은 유지한다. 상세 동작·소프트웨어 검사·남은 실기기 확인은 [활동 설계](centripetal-acceleration-design.md)에서 관리한다.

**M8-2 P4 구현:** 분석 화면의 **연속 기록 / 한 점 기록**은 분석할 자료 선택이며 측정 방식 전환과 구분한다. 같은 분석 도구를 사용하되 자료별 축·범위·제외·계산·근거·해석을 보존한다. 조건값 편집 확정은 분석에 자동 반영하고, 보관 근거에는 당시 조건값을 고정한다. 한 점에서 연속 원자료의 해당 시점으로 이동·복귀할 수 있게 한다. [상세 분석 UX와 입력 계약](point-recording-design.md#8-분석-ux와-원자료-추적)을 구현 기준으로 사용한다.

관계 그래프는 가로축 하나를 유지하고 기본 세로축에 `[+]`로 오른쪽 비교 항목 하나만 추가하며 다시 제거할 수 있다. 같은 물리량·단위의 방향 성분과 크기는 하나의 스케일을 공유하고, 다른 물리량은 좌우 축을 쓴다. 추세선·연장은 각 세로축 아래에서 따로 조작하며 공간이 충분하면 나란히, 좁으면 줄을 바꿔 표시한다. 그래프 모양은 제목 오른쪽 메뉴에, 계산 열 추가는 표에 둔다. 분석 화면과 그래프의 최대 폭을 제한하며 작은 화면에서는 축 조작을 아래로 재배치한다. 넓은 화면은 상하단 조작·통계의 실제 높이를 제외한 공간을 그래프와 표에 배분한다. 상세 설명·선택한 자료 정보·글자 확대에 필요한 공간은 최소 그래프 높이와 함께 보장하고, 부족하면 페이지 스크롤을 허용한다.

분석 중 새 자료가 도착해도 확정 구간, 제외 사유, 계산 열, 보관한 근거와 글을 유지한다. 보관한 근거는 당시 분석 조건의 사본이며 사용자가 명시적으로 교체할 때만 변경한다.

시간 그래프는 첫 수신을 0으로 하는 **경과 시간**으로 표시하며 구간 선택·자료 제외로 기준점을 옮기지 않는다. 축 제목에 실제 시각을 덧붙이지 않고, 눈금 간격에 맞춰 초·분·시간 및 필요한 소수 자릿수를 표시한다. 측정·원자료·관계 그래프·결과 해석·PNG·인쇄는 같은 눈금 규칙을 사용한다. 측정의 최근 범위는 기존의 ‘지금으로부터’ 기준을 유지한다. 공통 측정 그래프는 최근 10초·최근 60초·전체를 제공하며, 기본값은 최근 10초다. 내장 온도·방수 프로브·온도/기압 센서는 최근 60초, 게이뤼삭 활동은 전체를 기본으로 한다. 상세 수신 시각과 원자료는 정밀도를 유지한다.

축 설정은 넓은 화면에서 처음에 펼치고 모바일에서는 접어 가로축 요약과 채널 색상의 세로축 범례를 먼저 보여 준다. 펼친 상태에서는 축 이름·선택창·추가/제거 버튼을 같은 줄에 배치하고 관련 옵션을 아래에 둔다. 추세선 연장은 추세선을 켰을 때만 표시한다. 사용자가 정한 접힘 상태는 같은 분석의 탭 이동·화면 크기 변경 동안 유지하는 화면 상태이며 축·추세선·원자료·저장된 분석 정의를 변경하지 않는다. 접힌 조작은 키보드 탐색에서 제외하고, 전환 효과는 동작 줄이기 설정을 따른다.

한 점 자료의 **기록 선택**은 표를 열어 체크한 행으로 분석 범위를 정한다. **전체 기록 분석**으로 전체 범위로 돌아갈 수 있으며 제외 사유는 유지한다. 시간 구간 조작은 연속 자료에만 제공한다. 원자료 그래프는 표시하는 각 채널의 색상·이름·단위를 범례로 함께 제공한다. 분석 하단의 메모도 측정 화면과 같은 편집창으로 수정하며 원래 시각을 유지한다.

분석 개수·전체/지정 구간·제외 개수는 공통 범위 요약에서 안내하며 제외 0개와 제목 옆의 중복 개수는 생략한다. 모바일에서는 요약을 왼쪽 좁은 칸에 세로로 배치하고 구간 수정·실행 취소/다시 실행을 오른쪽 같은 줄에 둔다. 그래프의 유효 자료 수가 범위 요약과 다를 때만 축별 표시 개수와 결측 안내를 표시한다. 새 자료 반영과 표의 필터 결과·행 위치 안내는 유지한다.

분석 CSV는 현재 분석 범위와 제외 결과를 기준으로 출력 행 수를 안내하고 내보낼 계산 열을 선택하게 한다.
원자료·분석 CSV에는 수신 시각과 경과 초를 함께 저장한다. 일부 구간을 다시 열어도 원래 경과 시간을 유지한다. 두 시간 열의 기준이 행마다 다르면 ‘원본 시각 기준으로 복원’과 ‘취소’만 제공한다. 복원하면 수신 시각을 유지하고 파일의 첫 유효 수신을 0초로 경과 시간을 다시 계산한다. 취소하면 현재 실험을 유지하며, 잘못된 수신 시각이나 측정값은 복원으로 우회하지 않는다.
원자료 열은 항상 포함하며 다시 가져올 수 있는 숫자 열 한도 안에서 선택한다. 계산식 전체와 근거·해석은 전체 실험 JSON에 보관한다.

채널별로 **0 / 결측 / 미지원 / 범위 밖 / 측정 오류**를 구분한다. BMP280의 미지원 습도를 0%로 대체하지 않는다. 내장 온도는 보드 온도 기반 근사이며, 밝기·소리 크기의 0–255는 상대값임을 안내한다. 고속 진동 등은 장치 측정 시각·간격의 정확성을 검토한 뒤 지원한다.

## 8. 도구 공유와 후속 교사 자료 공유

### 8.1. 기본 도구 공유 — M3

**2026-10-26 최종 결정:** 기본 공유는 **도구 미리보기에서 보고 있는 실험 소개 페이지의 링크·QR을 제공하는 기능**으로 한정한다. 공유 대상을 따로 선택하지 않으며 홈·준비·측정·분석·저장 목록에는 공유 UI를 추가하지 않는다. 장치 연결·로그인·저장 서버는 필요하지 않다.

| 화면 | 표시와 조작 |
|---|---|
| 데스크톱 미리보기 | 넓은 화면은 소개 오른쪽, 좁은 데스크톱은 소개·시작 버튼 아래에 공유 영역을 왼쪽 정렬. 하단 공유 영역은 왼쪽에 제목·안내와 두 줄 버튼(첫 줄 **링크 복사**, 둘째 줄 **크게 보기 · QR 저장**)을 쌓고, 오른쪽 QR은 왼쪽 내용 전체 높이에 맞춰 배치. QR의 흰 여백은 유지한다. 데스크톱 공유 제목은 본문보다 뚜렷한 크기로 표시. 크게 보기는 확대 QR을 여는 대화상자 |
| 모바일 미리보기 | 실험 제목 옆 **도구 공유** 버튼을 누르면 큰 QR과 **링크 복사 · QR 저장**을 보여 주는 대화상자 |

공유 안내는 **‘실험 소개 화면으로 연결됩니다.’** 한 문장만 사용한다. QR은 표시 시 자동 생성하며 별도의 생성 버튼·설정 단계는 두지 않는다. QR 저장은 PNG 파일로 제공한다. 확대·모바일 대화상자를 닫으면 기존 미리보기와 버튼으로 돌아온다. 링크 복사 성공을 짧게 알리고, 복사가 차단되면 직접 선택할 수 있는 주소를 제공한다. QR 생성·저장 실패 시에도 링크 복사는 유지한다.

센서·활동의 공유 주소는 `sensors/bmp280/?view=preview`, `activities/gay-lussac/?view=preview`처럼 **현재 미리보기의 공식 주소**를 사용한다. 복사·화면 QR·저장 QR은 모두 같은 주소다. 수신자는 같은 소개 화면에서 **처음부터 준비하기 / 이미 준비했어요**을 선택한다. 기존의 직접 준비 주소는 그대로 지원한다.

공유 조작은 기록·연결·분석을 변경하지 않는다. 주소에 `mock`, 임의 검색 매개변수, 로컬 실험 ID와 파일 내용을 포함하지 않는다. 공유 링크를 연 학생에게 자동 연결·기록 시작·기존 실험 덮어쓰기를 수행하지 않는다. 앱 안에서 다른 실험으로 이동할 때는 §3.3의 저장·종료 규칙을 따른다.

공개 기준 주소는 배포 설정으로 제공한다. 앱을 다른 도메인이나 하위 경로로 옮겨도 이 설정과 등록된 내부 경로로 링크를 생성한다. 개발 서버 주소를 공식 공유 주소로 자동 선택하지 않으며 공개 주소가 설정되지 않으면 공식 링크 생성이 불가능함을 알린다. 같은 설정을 링크 미리보기의 OG URL·이미지 주소에도 사용한다. 공식 주소는 **`https://lab.sco.pe.kr/`**이며 Cloudflare 운영 배포와 포털 연결을 완료했다. GitHub Pages 자동 배포는 해제했다. 전환 순서는 §8.3을 따른다.

기존 계획의 수업 제목·안내 편집, 표시 설정 전달, 압축 `cfg` 코덱, 교사용 학생 화면 미리보기, 구형 v1 설정 링크 복원은 M3에서 제외한다. 현재 앱의 미지원 `cfg` 오류 안내를 유지하며 잘못된 링크를 임의 기본 실험으로 바꾸지 않는다. 기존 JSON·CSV 파일 호환은 유지한다. 페이지의 OG 이미지·문구는 링크 미리보기이며 수업 자료 공유 기능과 구분한다.

### 8.2. 교사 자료 공유 — Cloudflare 연계 후의 별도 단계

교사가 실험 JSON을 바탕으로 수업 제목·질문·짧은 안내와 분석할 자료를 공유한다. **원측정값·조작 기록·교사 안내를 전달하고 학생은 새로 분석한다.** 센서·활동 참조, 채널·단위·시각·유효성 등 자료 해석에 필요한 정보는 보존한다. 교사의 제외 구간·계산 열·회귀·보관 근거·해석 답안은 전달하지 않는다. 업로드 전 공유 내용과 조작 메모를 확인할 수 있으며 교사 원본은 수정하지 않는다.

흐름은 **JSON 검증 → 공유 자료 확인·안내 작성 → 업로드 → 학생용 링크·QR과 비밀 관리 링크 발급**이다. JSON 본문을 주소에 넣지 않고 서버에 저장된 자료의 식별자만 학생용 링크에 넣는다. 로그인은 요구하지 않는다. 비밀 관리 링크를 가진 사람이 자료를 삭제할 수 있으므로 학생용 링크·QR과 분리해 안내하고 보관하게 한다.

학생은 링크에서 수업 안내와 자료 개요를 확인하고 **내 분석 시작**으로 브라우저에 독립 사본을 만든다. 장치 없이 분석할 수 있고, 교사 원본과 다른 학생의 분석에 영향을 주지 않는다. 같은 링크 재방문 시 기존 사본 이어하기와 새 사본 만들기를 구분하며 진행 중인 분석을 초기화하지 않는다. 로컬 저장이 불가능할 때는 기존 파일 열기의 임시 분석·파일 보관 규칙을 따른다. 링크 열람만으로 사본을 계속 생성하지 않는다.

**보관은 서버의 생성 시점부터 30일이며 이후 자동 삭제한다. 연장 기능은 초기 범위에 넣지 않는다.** 교사는 그 전에 비밀 관리 링크로 즉시 공유를 종료·삭제할 수 있다. 관리 링크를 잃으면 복구·계정 확인을 제공하지 않고 자동 삭제를 기다린다. 학생용 링크만으로 삭제할 수 없다. 만료·삭제 시 새로운 다운로드를 막지만 이미 학생 브라우저에 저장된 사본은 지우지 않는다.

이 단계의 범위는 생성·링크 전달·조회·삭제·자동 만료다. 교사 계정, 수업 목록 서비스, 학생 답안 수집·제출·채점·동기화는 포함하지 않는다. Cloudflare 저장소·API는 공유 기능만 담당하고 기존 로컬 측정·저장·파일 열기는 독립적으로 유지한다. 무료 제공량을 무제한 사용 보장으로 취급하지 않으며, 실제 파일 크기를 바탕으로 업로드·총저장량 제한을 후속 구현 전에 확정한다.

### 8.3. 공식 도메인과 포털 연결

**2026-10-26 사용자 결정:** 포털은 `https://sco.pe.kr/`, 센서 실험실은 **`https://lab.sco.pe.kr/`**로 구분한다. 포털의 기존 소개 주소 `https://sco.pe.kr/tools/sensor/`는 유지하고 실행 버튼을 새 앱 주소에 연결한다. 센서·활동은 앱 아래의 기존 `sensors/<id>/`, `activities/<id>/` 경로를 사용한다. `sco.pe.kr/apps/sensor-lab/`에 앱을 중복 제공하지 않는다.

앱은 포털과 별도의 Cloudflare Workers Static Assets 배포로 운영한다. 먼저 기존 측정·분석 앱과 도구 링크·QR을 새 도메인에서 제공하고, 후속 단계에서 같은 주소의 `/api/shares`에 교사 자료 공유 API를 추가한다. 학생용 자료 링크는 `/share/?id=…`, 교사용 비밀 관리 링크는 `/share/manage/?id=…#token=…`으로 분리한다. 도메인 연결이 곧 서버 자료 공유의 구현 완료를 뜻하지 않는다.

2026-10-30 사용자 확인에 따라 센서 실험실은 기존 공개 배포가 없는 상태에서 공식 주소를 연결한다. 별도 이전 안내·구버전 빌드·동결 배포는 M5에 포함하지 않는다. 브라우저의 실험 자료와 USB/Bluetooth 권한은 origin별로 분리된다. 개발 확인 중 저장한 실험을 옮길 필요가 있으면 기존 전체 실험 JSON 내보내기·파일 열기를 사용하며, 새 주소에서 필요한 장치 권한을 다시 받는다. 시험 주소를 수업용으로 안내하지 않는다.

공식 전환은 새 주소의 HTTPS·직접 진입·자원·파일 복원 확인 후에 수행한다. 최종 공개 주소를 적용한 배포본에서 공개 링크·QR·OG·홈 화면 바로가기를 확인한 뒤 포털의 앱 이름·설명·실행 주소·USB/Bluetooth 지원 환경을 맞춘다. 포털에 남은 ‘센서 데이터 대시보드’와 ‘설정 링크·QR 공유’ 설명은 실제 센서 실험실 기능에 맞게 수정하되, 미구현 교사 자료 공유를 사용 가능한 기능으로 소개하지 않는다. 구현·배포 책임, 접근 환경과 전환 검사는 [기술 설계 §12.4](unified-sensor-lab-architecture.md#124-도메인-연결과-배포-전환)를 따른다.

## 9. 구현 경계

- **App/Navigation:** 앱 홈과 센서·활동 직접 진입, 구성 검증, 화면 전환, 현재 실험 복귀와 앱 이탈 처리. 배포 위치는 외부 설정으로 수신.
- **Sensor Registry:** 채널·단위·유효성, 펌웨어·배선·보정, 수신 해석.
- **Activity Registry:** 준비 단계, 빠른 메모 내용, 탐구 질문과 기본 분석.
- **Device Adapters:** USB 전송, BLE 수신, 상태와 오류.
- **RunStore/Repository:** 실험·원자료·사건·분석·복원.
- **Analysis Engine:** 표 투영, 계산, 구간, 회귀, 근거 보관.
- **Tool Share(M3):** 미리보기 중인 도구의 공식 소개 주소를 링크 복사·QR 표시·확대·PNG 저장으로 제공. 측정·분석 상태를 변경하지 않음.
- **Teacher Material Share(후순위):** 실험 JSON 기반 공유 자료 업로드·조회·만료·삭제, 학생의 독립 분석 사본 생성. 기본 도구 공유·로컬 측정은 이 서버에 의존하지 않음.
- **UI:** 공통 준비·측정·분석 화면과 도움말.

센서·활동 정의는 작은 모듈로 시작한다. 데이터로 표현하기 어려운 활동별 동작만 함수로 분리한다. 임의 플러그인 시스템, 코드 생성 서버, 여러 장치 동시 수집, 실시간 학급 관리와 활동 제작 편집기는 첫 버전 범위에서 제외한다.

**M4 완료(2026-10-26):** 대용량 기록·분석·파일 왕복, 실제 탭 종료 복원, 저장 실패·탐색·접근성의 소프트웨어 인수 검증을 마쳤으며 사용자의 최종 완료 지시로 단계를 종료했다. 수업 사용성은 별도 미완료 항목으로 남기지 않는다. 실제 검사 범위·소요 시간과 완료 근거는 [M4 검증 현황](history/m4-verification.md#m4-검증-현황--2026-10-26)을 따른다.

첫 통합판의 대표 경로는 **BMP280 자유 측정 / 게이뤼삭 활동 / 내장 자기장 자유 측정**이다. 세 경로 모두 앱 주소로 바로 진입할 수 있어야 한다. M2 확장으로 **내장 온도·밝기(조도)·가속도 자유 측정**도 같은 준비·기록·저장·분석 흐름에 추가했다. 밝기는 0–255 상대값이며 가속도는 중력을 포함한 X·Y·Z·크기를 기록한다. **2026-10-26 사용자가 실기기 검증 완료를 확인하여 M2를 완료 처리했다.** 이후 주요 외장 센서, 조건별 값 기록과 새로운 특화 활동은 M8에서 관리한다.

**보류·선택 항목:** 자동 배포 연결은 보류한다. MLX90393 3D 모델과 다른 확장 보드 선택 UI는 후속 범위다. 구심가속도 외 추가 특화 활동, pH 센서와 중화반응 활동은 조사 단계이며 구현 범위는 미확정이다. 배경 자기장 차감은 개발용 계산 로직만 보관하고 탐구 적용 여부는 미정이다.

**별도 검토 목록:** 본딩을 요구하는 전체 DFU는 M6 제품 범위에서 제외하고 기존 개발 시험·실패 기록만 보존한다. 네이티브 앱 제작은 확정하지 않는다. 공통 런타임 안의 부분 전송은 M6-2에 포함하며 지원 환경은 실물 검증으로 확정한다. 고속 측정을 위한 장치 timestamp·sequence, 사용자 정의 프로그램·임의 센서 조합도 구체 수업 요구와 호환 계약을 정한 뒤 판단한다. 오프라인/PWA·백그라운드 기록, 여러 장치 동시 수집, 실시간 학급 관리·활동 제작 편집기 등 기존 범위 밖 항목을 M5–M8의 필수 구현으로 자동 편입하지 않는다.

**상태 관리:** 각 단계는 자신의 산출물과 관련 검증·운영 반영으로 독립적으로 완료 판정한다. 제안·대상 미정 항목은 먼저 채택·보류·제외 결정을 기록하고, 채택 시 범위와 완료 기준을 확정한다. 단계 안의 미구현 항목을 남긴 채 완료로 표시하지 않으며, 보류 항목은 별도 목록으로 이관 근거를 남긴다. 이미 구현한 도구 링크·QR·아이콘과 M2·M4 인수는 후속 단계에 다시 넣지 않는다. 기존 실기기·브라우저별 미확인 범위는 검증 기록으로 보존하고 새 기능으로 세지 않는다.

## 11. 검증과 전환

검증할 핵심 상황은 첫 센서 선택과 실제 수신, 준비 단계의 차등 표시, 미리보기와 기록의 분리, 측정 중 분석 이동, 원자료 보존, 분석 상태 유지, 저장 실패·복원, 도구 링크 재진입, QR·링크 동등성, 게이뤼삭 CSV·JSON의 안전한 가져오기다. 구형 cfg는 지원되지 않는 링크임을 명시하고 임의 기본 실험으로 바꾸지 않는다. 후속 교사 자료 공유의 만료·삭제·학생별 사본 검사는 그 기능을 구현할 때 추가한다.

탐색과 관련해서는 앱 홈과 센서·활동 직접 경로의 새 탭 접속·새로고침·뒤로 가기, 내부 경로에서 필요한 스크립트·그림·HEX 로딩, 잘못된 경로·cfg의 복구, 기록 중 홈 이동의 저장·연결 종료, 미리보기의 장치 권한 차단, 다른 구성의 독립 준비, 미저장 분석이 있는 상태의 앱 이탈을 확인한다. 앱의 공개 기준 주소가 달라져도 내부 경로와 공유 링크 생성이 정상 동작하는지 시험한다. 검증은 변경된 범위에 집중한다.

현재 운영 주소는 Cloudflare의 `https://lab.sco.pe.kr/`이며 main 기준 배포·DNS·포털 연결을 확인했다. 센서·활동 직접 진입, 공개 링크·QR·OG·파일 복원은 [배포 기록](m5-deployment.md)의 검증 범위를 따른다. 작업 브랜치의 기능은 main 병합·배포 이후 운영에 반영한다. 새 주소의 사용자 USB/Bluetooth 권한 승인·실물 수신은 대기 상태이며 자동 검사를 실기기 확인으로 간주하지 않는다. 교사 자료 공유는 미구현이다. 단계별 현재 상태는 [진행 현황](UNIFIED-PLAN-INDEX.md)에 정리한다.

### 활동별 기록 UI

구심가속도와 게이뤼삭은 연속 기록으로 고정하고, 연속 측정 탭만 유지한다. 한 점씩 측정 탭과 연속 기록 토글은 숨긴다. 구심가속도는 한 점 기록 UI와 분석 자료 선택창을 숨기며, 게이뤼삭은 안정된 상태를 기록하기 위한 한 점 기록·표·분석을 유지한다. [기존 자료 보존과 활동별 규칙](point-recording-design.md#활동별-측정-방식)을 따른다.
