# M2 구현 결정과 인수 기록

2026-10-19~25 센서·활동 선택, 직접 진입, 장치 준비와 USB/BLE 연결을 구현·보완했다. **2026-10-26 사용자가 실기기 검증 완료를 확인하여 M2를 완료했다.** 현재 기능 계약은 [기획](../unified-sensor-lab-plan.md)과 [기술 설계](../unified-sensor-lab-architecture.md), 개발 명령은 [README](../../README.md)를 따른다.

## 채택·제외 결정

| 결정 | 이유와 결과 |
|---|---|
| 준비 UI와 활동 안내 복원 | 상태 로직·3D 자원만 이식해서는 원본의 준비 경험이 보존되지 않았다. 큰 단계/세부 단계, 그림·설명 병렬 배치, 이전/주 행동, 물품 도움말과 빠른 준비 경로를 복원했다. |
| 원본 3D·활동 자원 재사용 | 배선 모델을 다시 만들지 않고 단계별 선·단자·시점, 표 대체·재시도와 지연 로드를 연결했다. 용기 배치 SVG와 안내 그림 세 장은 원본 해시를 유지했다. 현재 버튼과 이름이 다른 기록 그림은 HTML 안내로 대체했다. |
| 준비 확인과 기록 허용 분리 | 10월 20일 사용자 결정으로 필수 체크를 측정 진입 조건에서 제외했다. 현재 장치의 정상 연속 수신을 기준으로 기록을 허용하되 보정·배터리·배치 확인을 자동 생성하지 않는다. |
| 자기장 v2 보정 선택 | 보정 시작/생략을 장치 응답과 연결하고 생략을 완료로 표시하지 않는다. 미배포 v1 호환은 요구하지 않는다는 결정으로 설치 허용 목록을 v2로 교체했다. |
| 수신 사실의 작성자 통합 | Transport가 실제·모의 장치의 준비 수신 사실을 공급하고, GuideProgress는 확인 이력, Session은 기록 수명을 맡도록 중복 판정을 제거했다. |
| 표시와 수집 분리 | 표시 채널을 숨겨도 모든 채널을 저장한다. 전체 그래프는 미리보기 버퍼가 아닌 기록 전체를 사용하고 일시정지·재연결 공백을 보존한다. |
| 센서·활동 모듈 등록 | 내장 온도·밝기·가속도와 준비 내용을 모듈로 추가했다. 공통 저장·분석기에 센서별 분기를 추가하지 않았다. 온도+밝기 예제는 빌드 전용으로 유지했다. |
| 새 실험·추가 측정 경계 | 10월 24일 실험 선택으로 나갈 때 저장 후 연결과 현재 실험을 닫도록 정했다. 25일에는 장치 출처가 확인된 호환 JSON만 새 연결·수신 확인 후 명시적으로 이어 측정하도록 보완했다. |
| 구형 대시보드 운영 종료 | 10월 20일 사용자 결정으로 기본 주소를 새 앱으로 전환했다. 구형 설정 편집·압축 cfg 복원·자동 재연결·별도 수집 엔진은 이식하지 않았다. 기본 도구 링크·QR과 후속 교사 자료 공유는 별도로 설계했다. |

준비·USB·UART·활동 자원은 고정 원본 `bme280@59c5c149450f970bace2deaa183857c275595853`을 기반으로 했다. 원본 경로·변경 목적·라이선스는 [외부 자원 고지](../../THIRD_PARTY_NOTICES.md), [활동 자산](../../public/activities/gay-lussac/README.md), [3D 자산](../../public/viewers/bmp280/README.md)에 보존한다. 재현 가능한 현재 빌드 절차는 [펌웨어](../../dev/firmware/README.md)와 [USB 라이브러리](../../dev/usb-library/README.md)를 따른다.

## 소프트웨어 검증 근거

| 범위 | 확인 결과 |
|---|---|
| 준비·복구 | 탐색만으로 확인 이력이 생성되지 않음, 명시적 이전 장치 재연결, 새 연결의 보정 근거 무효화, 수신 유효성 만료, USB 취소·실패·진행률·재시도를 검사했다. |
| 배선·활동 안내 | 실제 WebGL 로드·단계 적용, 실패 뒤 배선표·재시도, 자기장 경로의 3D 미요청을 확인했다. 안내를 열어도 기록이 유지되고 닫으면 초점이 복귀했다. |
| 표시·원자료 | 1,010행 전체 표시가 미리보기 600행으로 잘리지 않았다. 자기장 X만 표시해도 네 채널이 저장되고 JSON/CSV로 왕복했다. |
| 화면 크기 | 1366×768·1920×1080에서 배선 그림·설명·행동을 함께 표시했다. 390×844·683×384 CSS 영역에서 준비·측정·안내의 가로 넘침과 팝업 경계를 확인했다. 683×384 검사는 실제 브라우저 확대 조작과 구분한다. |
| 저장·호환 | 실제 IndexedDB 원자 저장·실패·잠금, 분석·근거·해석 재열기, 원본 게이뤼삭 v1/v2 JSON·CSV 및 대시보드 CSV 호환을 확인했다. |
| 확장·펌웨어 | 시험용 센서·활동의 등록·버전 선택·단계 충돌을 검사했다. 다섯 소스를 실제 빌드해 공식 V2 해석·내장 소스·설정을 확인했고 당시 자기장 재빌드 해시와 BMP280 고정 HEX가 유지됐다. |

단계별 실행은 서로 다른 범위이며 검사 수를 합산하지 않는다.

| 당시 변경 | 통과한 검사 |

| 공통 펌웨어 빌드 | 실제 빌드 3대상·자기장 해시 일치, Node 147개, 타입·빌드 |
| 내장 온도·밝기·가속도 통합 | Node 153개, 브라우저 35개, 타입·빌드 |

위 통신·USB 입력은 모의다. 실물 센서의 정확도나 모든 브라우저·OS 동작을 검증한 결과로 확대하지 않는다.

## 실기기 확인과 완료

- 10월 19~20일 micro:bit V2에서 내장 온도·밝기·가속도의 USB 설치, BLE 수신, 기록·저장·분석 재열기를 직접 확인했다. 관측 수치와 재연결 결과는 [실기기 관찰 기록](hardware-acceptance-2026-10-19.md)에만 유지한다.
- 10월 20일 사용자가 자기장 v2 실기기 확인 완료를 알렸고, 26일 M2 실기기 검증 완료를 최종 확인했다.
- 사용자 인수는 완료 결정이며 새로운 계측 로그가 아니다. 당시 관찰하지 않은 정확도·배터리 지속 시간·개별 오류 결과를 추가하지 않는다. 대용량·탭 종료 복원 등 후속 소프트웨어 근거는 [M4 기록](m4-verification.md)을 따른다.
