# 구현·검증 이력

완료된 작업의 결정 근거와 당시 관찰 결과를 보존합니다. 현재 상태는 [문서 안내](../UNIFIED-PLAN-INDEX.md), 사용·개발 명령은 [README](../../README.md), 계약은 [기술 설계](../unified-sensor-lab-architecture.md)를 따릅니다.

| 기록 | 보존 내용 |
|---|---|
| [M1 구현](m1-implementation.md) | 공통 저장·분석 이식 및 파일 호환 검증 |
| [M2 구현·인수](m2-implementation.md) | 원본 대비 채택·제외 결정과 센서·준비·연결의 검증 근거 |
| [실기기 관찰](hardware-acceptance-2026-10-19.md) | 실제 기록 수·수신 간격·복원 관찰과 사용자 확인 |
| [M3 구현·배포](m3-implementation.md) | 도구 공유·아이콘의 검증 및 릴리스 범위 |

각 기록의 검사 수·미확인 범위·배포 상태는 당시 기준입니다. 자동 검사·실물 관찰·사용자 인수 결정은 구분해 유지합니다. 이후 단계가 완료됐다고 과거 관찰 결과를 새 검증 결과로 다시 쓰지 않습니다.
