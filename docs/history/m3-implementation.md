# M3 구현·배포 검증 기록

> 2026-10-26 당시 기록입니다. 현재 상태는 [문서 안내](../UNIFIED-PLAN-INDEX.md)를 따릅니다.

**M3 진행 현황(2026-10-26):** 미리보기 링크·QR·확대·PNG 저장과 배포별 공개 주소 설정을 구현했고, 반응형 공유 배치를 확정했습니다. 좁은 데스크톱에서는 소개 아래 왼쪽에 제목·안내와 두 줄 버튼을 쌓고 오른쪽 QR을 같은 높이로 배치합니다. 상세 사용 흐름은 [기획 §8.1](../unified-sensor-lab-plan.md#81-기본-도구-공유--m3)을 따릅니다.

- **기능 검증:** 구현 시 관련 단위 검사 5개, 공유 브라우저 검사 4개와 기존 startup·navigation suite, 타입 검사·빌드를 통과했습니다.
- **최종 배치 확인:** 좁은 데스크톱 761·820·1024·1150px에서 제목·버튼 영역과 QR의 위아래 정렬 및 가로 넘침 없음을 확인했습니다. 넓은 데스크톱·모바일 화면은 앞선 구현 단계에서 확인했습니다. 배치 수정 중에는 범위별 확인을 수행하고, 커밋 전 전체 검사 결과는 아래 릴리스 검증에 기록합니다.
- **코드 검토:** 배치 변경의 중복·폐기 스타일이 남지 않았고, 공통 버튼 스타일과 UI·링크·QR 모듈 분리를 유지함을 소스에서 확인했습니다. 추가 코드 수정은 없었습니다.
- **남은 작업:** 실제 휴대폰 카메라의 화면 QR·저장 PNG 판독과 주요 브라우저·기기에서의 아이콘 표시 확인. 새 도메인 연결은 별도 전환 작업이며 교사 자료 공유는 후순위 미구현입니다.

**2026-10-26 릴리스 검증:** 도구 공유와 파비콘·홈 화면 아이콘을 이번 릴리스에 포함합니다. 커밋 전 타입 검사, 전체 단위 검사 188개, 빌드, 전체 Playwright 검사 30개(기존 브라우저 suite 16종 포함)를 통과했습니다. 수정 문서의 로컬 링크·앵커 104개를 확인했습니다. 파비콘은 보정 SVG와 16·32·96px PNG, 홈 화면은 기본형 SVG와 기존 PNG를 제공합니다. PNG 크기·SVG 원본 일치·진입 페이지 연결·매니페스트 로딩을 확인했으며 주요 브라우저의 실기기 설치·표시는 별도 확인 대상입니다. 운영 배포 결과는 [GitHub Pages 워크플로](https://github.com/Cho-WH/MicrobitSensorDashboard/actions/workflows/pages.yml)에서 해당 커밋으로 확인합니다.
