# M4 인수 기록

## M4 검증 현황 — 2026-10-26

**M4 완료(2026-10-26): 소프트웨어 인수 검증 결과와 사용자의 최종 완료 지시에 따라 단계를 종료했다.** 수업 사용성은 별도 미완료 항목으로 남기지 않는다. M2는 사용자의 실기기 검증 완료 확인으로 인수를 마쳤다. 이번 M4 자동 검사는 Windows의 격리된 Playwright Chromium에서 수행했으며, 사용자가 열어 둔 앱의 자료·장치·서버는 건드리지 않았다. 교사 자료 공유와 공식 도메인 전환은 별도 후속 작업이다.

| 항목 | 확인한 결과와 근거 |
|---|---|
| 대용량 기록·저장 | 가속도 4채널·100ms 간격 시각의 36,000행을 Session으로 시간 압축 입력하고 실제 IndexedDB에 600행씩 60회 저장. 모든 행의 순서·시각·값 일치. [대용량 검사](../../tests/browser/large-recording.js) |

**성능 관찰:** 마지막 대용량 실행에서 증분 기록·저장 14.6초, 측정 네 채널 전체 표시 전환 0.16초, 분석 열기 0.59초, 관계 그래프 전환 1.18초, 회귀 적용 0.78초, 새 자료 반영 0.82초, PNG 생성 0.33초, DB 재열기 0.40초, JSON의 새 DB 가져오기 9.34초였다. UI 수치는 작업 실행과 두 프레임 대기를 포함한다. 이 PC의 단일 관찰이며 저사양 기기에서의 지연 보증이 아니다. 36,000행은 한 시간 **분량**의 검사이며 실제 한 시간 BLE 수신·배터리 지속 시간 검사가 아니다.

**실행 결과:** 범위별 실행을 합쳐 Playwright 검사 8개(기존 브라우저 묶음 6개, 새 대용량 묶음 1개, 실제 탭 종료·파일 복원 1개)가 통과했다. 새 복원 검사의 설정 창 진입 누락과 저장 목록 순서 가정을 수정한 뒤 해당 검사를 재실행했다. 앱 기능의 수정이 필요한 오류는 발견하지 않았다. 대용량·복원 검사는 정식 회귀 검사로 편입했으며, 기존 검사를 복제하지 않았다. 앱 코드·의존성·빌드 입력을 바꾸지 않아 타입 검사·빌드·전체 검사는 반복하지 않았다. 이번 변경은 커밋·배포하지 않았다.

**검증 기록의 범위:** 사용자의 완료 지시는 단계 인수 결정으로 기록한다. 별도의 학생·교사 관찰 기록이나 장시간 실물 수신, 저사양·다른 브라우저 엔진·모바일의 성능 및 보조 기술 검증을 이번 자동 검사 결과에 추가하지 않는다. 이러한 검증 범위를 이유로 M2·M4를 미완료로 표시하지 않는다.
