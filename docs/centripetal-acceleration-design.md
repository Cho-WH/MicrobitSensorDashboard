## 목표
수평 회전판에 고정한 micro:bit V2의 가속도 X·Y·Z·크기와 자기장 크기, 총 5개 측정값을 함께 기록한다. 고정 자석의 통과 시각으로 회전 주기를 측정하고, 가속도 센서값으로 별도로 구한 구심가속도와 비교한다. 학생이 기준점 두 개와 그 사이 회전수를 직접 정하고 앱은 시간 차이·주기의 계산 과정을 돕는다. 구간 선택선은 가까운 자기장 피크에 가볍게 붙도록 보조하며, 선택한 주기 측정과 동일한 구간의 가속도 자료를 연결해 비교한다.

## 장치·물리 조건
보드와 배터리를 원판에 단단히 고정하고 자석과 회전부의 충돌·케이블 이탈을 방지한다. 회전축에서 **가속도 센서 칩**까지의 반지름 r을 측정한다. 센서 칩 위치는 기존 공통 장치 그림으로 안내한다. 정지 상태의 가속도 크기는 약 9.8 m/s²이며 이 확인값으로 계산 기준을 보정하지 않는다. 회전을 기록하며 실제 한 바퀴와 자기장 신호의 반복 특징을 대응한다. 모든 봉우리를 한 바퀴로 가정하지 않으며 자석·배터리·주변 금속의 자기장 간섭에 주의한다.

이상적인 수평 등속 회전에서는 a_period=4π²r/T², a_sensor≈sqrt(mean(|A|)²-g_ref²)이다. |A|는 가속도계가 감지하는 specific force(단위 질량당 비중력 힘)의 크기다. 정지 상태에서는 지지력 때문에 약 g가 나타나며, 수평 등속 회전에서는 수직 지지 성분과 수평 구심 성분의 크기 관계를 이용한다. 활동 계산의 중력 기준은 g_ref=9.8 m/s²로 고정한다. 정지 구간을 선택해 기준값을 바꾸거나 별도 중력값을 입력하는 기능은 제공하지 않는다. 이 값은 활동 계산의 근삿값이며, 기존 가속도 원자료의 mg→m/s² 단위 환산 상수(9.80665)는 유지한다. mean(|A|)≤g_ref이면 계산 불가로 표시하며 0으로 대체하지 않는다. 저속에서는 두 크기의 차이가 작아 오차가 증폭된다. 기울기·진동·접선 가속도·센서 축 정렬도 한계로 설명한다. 구심가속도 비교는 가속도 크기를 이용하는 방식으로 한정하며, 축 성분을 이용한 별도의 수평 성분 보조 분석은 제공하지 않는다. 가속도 X·Y·Z의 원자료 기록과 그래프 표시는 유지한다.

## 실험 방법 안내

2026-10-31 개편: [이전 실험과 활동지](https://physics-lab-archive.notion.site/3b1a485802c48153bd1ed5ea2cd36ca3)의 두 계산 경로를 유지하며, 게이뤼삭과 같은 공통 안내 팝업에 네 단계를 제공한다. 설치·연결은 기존 장치 준비에서 맡는다.

1. **장치 배치:** 보드·배터리 고정, 회전축부터 센서 칩까지의 반지름 측정, 원판 밖 고정 자석과 회전부의 간격 확인.
2. **측정 기록:** 측정 화면에서 반지름을 cm로 입력하고 m 환산값 확인, 기록 시작, 한 바퀴와 반복 신호를 대응하며 일정한 회전 기록, 기록 마치기와 자료 분석 이동. 별도의 신호 확인 페이지는 두지 않는다.
3. **구간 측정:** 가속도 크기와 반복 간격이 안정된 같은 구간 선택, 평균 구하기, 학생이 센 회전수 입력과 주기 적용. 그림은 같은 특징 여섯 개 사이 다섯 간격을 5회전으로 센 예시이며 실제 자료의 봉우리 수를 자동으로 회전수로 판정하지 않는다.
4. **분석·정리:** 기존 두 계산 영역과 결과 비교, 보고서 출력으로 짧게 안내한다. 상세 수식·오차 분석 발문은 실제 분석 화면에서 제공하며 안내에 중복하지 않는다.

단계별 시각 자료는 [구심가속도 안내 자산](../public/activities/centripetal/README.md)에서 관리한다. 공통 안내의 탭·이전/다음·닫기·기록 지속·열람 설정과 반응형 배치를 그대로 사용한다. 그림은 장치 배치와 자료의 연결을 설명하며 학생의 원자료나 계산 결과를 대신하지 않는다.

안내 개편 검증: 타입 검사, 준비·안내 단위 검사 11개, 구심가속도 모의 장치 브라우저 흐름을 통과했다. 320·390px 모바일과 1366px 데스크톱에서 네 장의 그림·본문·단계 이동을 확인했으며 실물 장치·실제 휴대폰 검증은 포함하지 않았다.

## 기록·분석 설계
장면별 검토 자료: [현재 앱과 연결한 이미지 시안 4장](design/review/centripetal-2026-10-30/README.md). 이전 대화형 시안은 폐기했다. 이미지의 도식·버튼 상태는 구현 계약이 아니며 아래 학생 입력·자료 보존 원칙이 기준이다.

2026-10-30 사용자가 설계와 [장면별 이미지 시안](design/review/centripetal-2026-10-30/README.md)을 승인하고 구현을 요청했다. **두 방법을 나란히 채워 가는 탐구 활동지**를 주 작업면으로 삼고, 측정값에 비례하는 성분 벡터와 기호·관계식을 표시한 원운동 개념도를 제공한다. 아래 동작은 작업 브랜치에 적용했으며 성분 벡터는 센서 측정 평균에 비례하며 원운동 그림은 고정된 형태에 기호·관계식을 표시한다.

### 1. 학습 목표와 원래 활동지의 연결
참고 실험의 활동지는 가속도 평균에서 구심가속도를 구하는 열과 주기·각속도·반지름으로 구하는 열을 나란히 두고, 성분 관계식·각속도식·구심가속도식을 학생이 설명하게 한다. 역할·새 시도·의미 있었던 과정도 기록한다. 후속 평가지는 다른 수치에 두 방법을 적용하게 한다.

이번 개편은 다음 판단을 학생에게 남긴다.
- 어떤 구간을 등속 회전으로 볼 수 있는가, 한 바퀴의 기준과 회전수는 무엇인가.
- 센서 크기와 구심가속도는 왜 다른가. 왜 단순히 9.8을 빼지 않는가.
- 주기에서 각속도를 거쳐 구심가속도로 어떻게 이어지는가.
- 두 결과의 차이를 자신의 자료로 어떻게 설명하고 다음 측정을 개선할 것인가.

앱은 많은 표본의 평균·시간 차이·자료 연결을 맡고, 학생은 반지름·회전수와 계산한 ω·두 구심가속도를 입력한다. 회전수 입력 시 주기 계산값을 곁에 표시하고 학생이 적용할 수 있다. 다른 계산 도움은 요청할 때 단계별로 제공하며 학생 입력을 자동 대체하지 않는다. 모든 원자료를 손으로 옮기거나 평균을 수작업하게 하지 않으며 새 답안 채점 시스템은 만들지 않는다.

### 2. 화면 구조
기존 준비·기록·분석·해석의 이동과 기록 수명은 유지한다. 구심가속도 활동에서 기록·분석의 **본문 구성**을 교체하고 일반 센서 화면을 일괄 변경하지 않는다. 그래프·원자료 표는 측정의 근거를 확인하는 도구로 남는다.

```text
기록
  기록 상태 · 경과 시간 · 기록 시작/일시정지/마치기
  가속도 관찰                         회전 기준 관찰
  현재 센서 크기 · 정지 기준          현재 자기장 · 짧은 반복 신호
  회전 조건 · 반지름 · 관찰 메모
  기록 후 [자료 분석하기]          [전체 신호·원자료]

분석: 구간·계산 (한 화면)
  접을 수 있는 구간 그래프
  가속도 측정 (절반)          | 주기 측정 (절반)
  측정 구간 → 구간 평균 가속도 | 걸린 시간 ÷ 내가 센 회전수 = 주기
  [평균 구하기]              | [주기 적용]
  두 측정값 준비 후 분석 자동 펼침
  ┌ 가속도 측정값으로 구하기 ──────┬ 주기로 구하기 ────────────┐
  │ 측정한 평균 A · g=9.8      │ N 입력 · Δt 확인 · r 입력 │
  │ 성분 관계 그림            │ 주기 T 적용값            │

  │ 측정 평균의 성분 관계    │ 나의 구심가속도 입력      │
```

구간 선택과 계산 사이의 단계 탭·이동 버튼·중복 요약 카드는 제거한다. 넓은 데스크톱에서는 그래프 오른쪽의 좁은 고정 폭 영역에 `가속도 측정`과 `주기 측정`을 같은 폭·제목 위계로 세로 배치하고, 그 아래 두 계산 열을 둔다. 중간 폭이나 그래프를 접은 상태에서는 두 측정 카드를 나란히 놓되 측정 영역 자체의 최대 너비를 제한한다. 활동지 전체 너비는 유지한다. 반지름·주기·각속도·주기 기반 구심가속도 입력은 두 칸씩 묶고, 상세 자료와 계산 도움은 기존 접이식 요소로 제공한다. 글자나 조작 영역을 과도하게 줄이거나 내부 스크롤을 여러 개 만들지 않는다. 작은 화면에서는 그래프·가속도 측정·주기 측정·분석 순서로 쌓는다. 주기 측정의 식과 세 값은 좁은 화면에서도 같은 가로 순서를 유지한다.

두 열에는 `자료 → 생각·계산 → 나의 결과`를 연결한다. 왼쪽 답을 맞혀야 오른쪽을 열 수 있는 잠금이나 완료 점수는 없고 미완성 입력도 보관한다. 두 계산 열을 번갈아 숨기는 탭은 쓰지 않는다. `결과 비교`만 별도 화면으로 이동하며 돌아오면 선택 구간·입력·그래프 접힘 상태를 유지한다.

### 3. 기록: 계산에 쓸 실험 자료를 모으기
기록 조작·수신/저장 상태·오류 복구는 기존 공통 요소를 그대로 사용한다. 기록 화면에서 구심가속도 정답이나 주기를 먼저 계산해 보여 주지 않는다.

- **가속도 관찰:** 현재 크기와 m/s² 단위를 크게 표시하고 정지 시 약 9.8이라는 기준을 구별한다. 이것은 현재 센서값이며 구심가속도가 아니다. 원판 위 센서 위치 그림은 반지름의 시작/끝을 설명하는 정적 그림으로 사용한다. XYZ는 상세 자료에서 확인한다.
- **회전 기준 관찰:** 현재 자기장 크기와 최근 신호를 작게 표시한다. 학생이 실제 한 바퀴와 신호 특징을 대응시켜 본다. 자동 회전수·속도계·실제 위치처럼 돌아가는 원판은 표시하지 않는다. 자기장 크기만으로 절대 회전각을 알 수 없기 때문이다.
- **회전 조건:** 그래프 위의 반지름 기록칸에 회전축에서 센서 칩까지 잰 거리를 cm로 입력하고, 옆에 m 환산값을 자동 표시한다. 기록·분석에는 기존 m 단위로 전달한다. 별도의 미리보기 보조 카드는 두지 않으며 관찰 사항은 공통 메모에 남긴다. 반지름 미입력은 기록을 막지 않는다. 장착 위치를 바꿔 다시 실험할 때는 기존 새 실험 흐름으로 조건을 분리한다. 이미 보관한 결과의 반지름은 덮어쓰지 않는다.
- **기록 순서:** 미리보기에서 느리게 2~3회전하며 기준 신호 확인 → 안정 회전 후 명시적으로 기록 시작 → 충분한 회전을 기록 → 기록 마치기 → 자료 분석하기(공통 기록 조작 자리). 회전수나 시간 목표를 자동 정하지 않고 20회전을 강제하지 않는다.
- **저장 의미:** 기록된 연속 자료 전체를 기존 Session/RunStore에 보존한다. 활동에서 사용할 구간은 나중에 고르는 참조이며 별도 수집 세션이나 잘린 원자료 사본을 만들지 않는다. 한 점 기록을 회전 주기 자료로 대신 사용하지 않는다.

별도 분석 이동 버튼은 두지 않고 상단 자료 분석 탭과 기록 종료 후 공통 자료 분석하기 버튼을 사용한다. 분석으로 이동해도 기존 기록이 자동 종료되지는 않는다. 계속 기록 중이면 상태를 보여 주고, 이미 선택한 분석 구간은 늘리지 않는다. 새 자료 반영은 기존 명시적 동작을 사용한다.

### 4. 공통 자료: 같은 회전을 두 방법으로 살펴보기
분석 첫 진입에는 두 측정 카드의 빈 결과칸과 비활성화된 분석 제목을 보여 준다. 가속도 평균을 구하고 유효한 N으로 주기가 계산되면 두 계산 열을 자동으로 펼친다. 평균만 구하거나 회전수만 입력한 상태에서는 열리지 않으며 키보드로도 비활성 분석을 열 수 없다. 학생은 준비 후 분석을 직접 접을 수 있고 일반 재렌더가 다시 펼치지 않는다. 결과 비교는 두 구심가속도와 필요한 계산 입력이 유효하고 재확인 항목이 없을 때만 사용할 수 있다. 구간 변경·무효 N·자료 오류로 준비 조건이 사라지면 분석을 접고 비활성화하되 기존 계산·메모는 보존한다. 실행 취소·복원으로 조건이 회복되면 다시 펼친다.

`구간 그래프`는 기존 시간 그래프·표·확대·공유 커서를 재사용한다. 자기장 크기와 가속도 크기를 같은 시간축에서 보고 학생이 A/B를 고른다. 처음에는 펼치고 학생이 직접 접을 수 있으며 구간 적용이나 주기 적용으로 자동으로 접지 않는다. 접으면 선택 시간·표본 수·가속도 평균·현재 T 입력을 요약하고 두 측정 카드와 회전수·주기 적용은 계속 사용할 수 있다. 다시 펼쳐도 선택 구간·확대 상태·계산 입력은 유지한다.

보기 전환 버튼은 전체 기록을 보는 동안 `선택 구간만 보기`, 선택 구간을 보는 동안 `전체 기록 보기`로 교체한다. 선택 구간 보기에서는 가로축의 양끝을 선택 시작·끝 시각에 맞춰 구간을 좌우로 확대하며, 원래 경과 시간 기준은 유지한다. 전체 기록 보기로 돌아오면 가로축도 전체 범위로 복원한다. 구간 미선택 시 선택 구간 보기는 비활성화한다. 같은 시각의 가속도 크기와 자기장 크기를 공통 차트 툴팁에 함께 표시하며 그래프 아래에 가변 높이의 값 표시 줄을 만들지 않는다. 보기 전환과 값 확인은 분석 구간·학생 입력을 변경하지 않는다.

세로축은 [공통 시간 그래프 범위 정책](../src/catalog/README.md#시간-그래프의-공통-축)을 사용한다. 가속도 크기의 기본 범위로 안정적인 구간의 작은 흔들림이 과장되지 않게 하고, 자기장은 주기를 판독할 수 있는 독립 범위를 사용한다. 선택 구간만 보아도 기본 세로축은 유지한다. 각 축 위의 ＋/− 돋보기 하나로 해당 축만 확대·복원하며, 계산 입력이나 구간 확정을 바꾸지 않는다.

- A/B는 실제 sampleId에 연결한다. 가장 가까운 표본이 유효하지 않으면 멀리 건너뛰거나 보간하지 않는다. 같은 거리에서는 앞선 표본을 택한다. B의 수신 시각은 A보다 늦어야 한다.
- 구간 선택은 공용 도구의 UI·조작을 재사용한다. 그래프 양끝 손잡이 드래그, 시작/끝 경과 시간 입력, 손잡이의 좌우·Shift+좌우·Home/End로 초안을 조절하고 구간 전체를 한 번에 적용한다. 전체 구간·취소도 공용 도구와 같다. 별도의 A/B 선택 모드와 표본별 확정 버튼은 제공하지 않는다. 적용 전에는 기존 구간·학생 입력을 바꾸지 않고, 적용할 때 가장 가까운 실제 표본 두 개를 하나의 실행 취소 단위로 확정한다. 원자료 표는 별도 탭에서 관찰용으로 제공한다.
- A/B 두 표본을 포함한 동일한 행 범위에서 가속도 평균과 주기 자료를 얻는다. 가속도만 별도 구간을 선택하거나 결측을 제외한 짧은 구간으로 자동 축소하지 않는다.
- Δt는 앱이 수신 시각 차이로 계산해 초로 표시한다. A/B와 다른 원자료의 평균을 섞지 않는다. 단위·자료 수·자료 공백 상태와 원자료로 가는 동작을 함께 제공한다.
- 학생은 반복 신호의 간격과 가속도 크기의 변화를 보고 구간을 선택한다. 구간 선택 이유의 별도 입력칸은 두지 않는다. 평균 주기만으로 등속을 판정하지 않으며, 자동 적합도·신뢰도 점수를 붙이지 않는다.
- 자동 후보 도움 버튼과 목록은 제거한다. 피크 흡착은 손잡이 드래그 초안만 보조하며, 회전수와 계산 입력은 자동으로 채우지 않는다. 외부 시계로 잰 시간/주기 입력 모드는 이번 구현에 추가하지 않는다.

활동지 한 건은 한 공통 구간과 두 계산 과정을 함께 보관한다. 다른 구간도 알아볼 때 학생이 새 활동지를 만들고 이름/구간으로 선택한다. 여러 활동지를 자동 평균하거나 N개의 개별 주기를 생성하지 않는다. 기존에 합의했던 독립적인 '주기 목록 → 비교할 행 다시 선택'의 이중 절차를 활동지 선택 하나로 단순화한다.

### 5. 왼쪽: 가속도 측정값으로 구하기
**자료:** `가속도 측정` 카드의 왼쪽에는 `측정 구간` 소제목 아래 선택한 경과 시간 범위를, 오른쪽에는 `구간 평균 가속도` 소제목 아래 빈 결과칸과 `평균 구하기` 버튼을 같은 줄에 둔다. 측정 구간의 경과 시간 기준과 가속도 크기의 평균이라는 설명은 각 소제목 옆 물음표의 공통 도움말 버블로 제공한다. 마우스·키보드·터치로 조회하며 단위는 결과칸에 표시한다. 걸린 시간은 상자 없는 숫자로, 자동으로 채워지는 평균·주기 결과는 밑줄 칸으로 표시해 흰 상자의 직접 입력칸과 구별한다. 회전수·반지름·각속도·두 구심가속도의 직접 입력칸은 같은 요소를 재사용하며 단위를 칸 오른쪽에 표시한다. 평균 확인·주기 적용 상태 문구와 전용 안내 영역은 제거해 높이를 줄이며, 입력 오류·재확인 안내는 유지한다. 버튼을 누른 뒤에만 평균을 표시하고 왼쪽 계산 영역에도 읽기 전용으로 연결한다. 구간을 바꾸면 다시 평균을 구해야 하며, 기존 학생 답은 유지한다. 확인 상태는 활동지·실행 취소·파일 복원·근거에 보존한다. 앱 내부 기호는 원자료 |A|와 평균 Ā를 구별한다. g=9.8 m/s²는 고정한다. 평균을 학생이 다른 숫자로 바꾸어 측정값인 것처럼 보관하지 못하게 한다. 표준편차·범위·결측 등 상세 통계는 `사용한 자료`에서 펼친다.

**학생 입력:** 센서로 구한 구심가속도 a_s [m/s²], 식이나 생각 메모. 자유 수식을 자동 판정하는 엔진은 넣지 않는다. 수치는 처음 비워 두고 입력은 학생의 계산 기록으로 보존하며 성분 그림은 측정 평균을 기준으로 표시한다. 0은 학생의 가설로 입력할 수 있지만 음수·비수치·무한대는 크기 표현에 사용할 수 없음을 안내한다.

**성분 벡터 개념도:** 납작한 직사각형 센서 모형을 수평으로 놓고 센서 사각형의 중심에서 세 화살표가 출발한다. 아래 방향은 중력가속도 g, 수평 방향은 구심가속도 a, 두 성분의 합성 대각 방향은 센서 가속도 Ā로 표시한다. 수평·수직 화살표 끝에서 대각선 끝까지 점선 보조선을 이어 직각 표시를 제공한다. 수평 방향의 관성계·회전계 구분 설명은 화면에 추가하지 않는다.

그림은 센서 기준 성분의 크기 관계를 설명한다. 중력 화살표 길이는 고정하고, 확인한 센서 평균 Ā/9.8의 비율로 대각선 길이를 정한다. 수평 성분 길이와 대각선 각도·보조선은 같은 축척의 직각 관계에 맞춰 갱신한다. 센서 사각형은 수평으로 유지한다. 그림에는 이름·기호만 표시하며 숫자는 생략한다. 학생이 입력한 답은 그림의 기준이 아니며 계산 답을 숫자로 공개·자동 입력하거나 정오 판정하지 않는다. 평균 미확인 또는 평균이 g보다 작으면 수평·대각 성분을 임의로 만들지 않고 안내한다. Ā=g이면 수평 성분은 길이 0이다. 벡터와 이름·기호의 전체 폭을 계산해 남는 폭의 가운데에 배치한다. 긴 벡터는 축척을 바꾸지 않고 가로로 살펴볼 수 있게 하며 출력은 종횡비를 보존한다. 측정값과의 막대 비교는 제공하지 않는다.

**요청 시 도움:** 직각 관계를 떠올리는 질문에 이어 `관계식과 값 대입`에서 수평 등속 원운동 모형의 관계식 Ā²=a²+g², a=√(Ā²−g²)를 제시하며 정리 이름과 일반 삼각형 설명은 생략한다. 평균을 구한 뒤 a 식에 평균과 9.8을 대입해 보여 준다. 계산 결과 공개·답 자동 입력 기능은 제공하지 않는다.

Ā≤9.8이거나 집계 불가이면 이 활동의 근사 계산을 보류하고 원인을 안내한다. 학생의 생각·입력과 오른쪽 주기 계산은 보존한다. 모형을 탐색하더라도 유효한 센서 계산 결과로 내보내지 않는다.

### 6. 오른쪽: 주기로 구하기
자료와 입력은 다음 순서로 놓는다.

| 항목 | 기본 동작 | 역할 |
|---|---|---|
| 걸린 시간 Δt [s] | A/B에서 읽기 전용 | 선택 구간의 자료 |
| 회전수 N [회] | 학생 입력, 양의 정수, 초기 공란 | 회전 판단 |
| 반지름 r [m] | 준비/기록에서 잰 값 연결, 직접 수정 | 장착 조건. cm로 측정했다면 m로 환산해 입력 |
| 주기 T [s] | 회전수 옆의 계산값을 `주기 적용`으로 반영하는 읽기 전용 밑줄 칸 | Δt/N의 의미 |
| 각속도 ω [rad/s] | 학생 계산·입력 | 2π/T의 의미 |
| 주기로 구한 구심가속도 a_p [m/s²] | 학생 계산·입력 | rω²의 의미 |

기록·분석의 반지름은 입력·계산·저장·출력 모두 m 단위를 사용한다. 활동·활동지 형식은 v2이며 cm 기반 v1 자료의 호환·자동 변환은 제공하지 않는다. 3을 넘는 값에는 노란 음영과 느낌표 도움말을 표시한다. 안내는 “단위를 확인했나요? 측정한 cm를 미터 단위로 환산해서 적으세요.”이며, 값을 자동으로 바꾸거나 입력을 막지 않는다. 느낌표는 입력칸 안 단위 뒤에 두고 기존 도움말 버블을 재사용한다. 조건 변경으로 붉게 표시된 입력·적용값에도 같은 느낌표를 두어 재확인 방법을 안내한다. 같은 계산값은 Enter로 확인할 수 있다.

`주기 측정` 카드에는 `구간의 걸린 시간 ÷ 내가 센 회전수 = 주기`를 한 줄로, 그 아래 해당 시간·회전수 입력칸·주기 결과칸을 맞춰 놓고 값 칸 사이에도 ÷와 =를 표시한다. 넓은 화면에서는 두 소제목이 줄바꿈되지 않을 만큼의 최소 카드 폭을 확보한다. 유효한 회전수를 입력하면 주기 결과칸을 즉시 채우며 무효 입력이나 바뀐 구간의 회전수 미확인 상태에서는 비운다. 주기 결과칸 옆 같은 줄의 `주기 적용`을 눌렀을 때만 계산 단계의 T에 반영한다. T는 기존 자동입력 결과와 같은 밑줄 양식으로 표시하며 직접 수정할 수 없다. `계산 도움에서 채택`을 비롯한 적용 상태 안내 줄은 두지 않는다. 적용값은 기존 계산 도움 채택 경로로 저장·실행 취소하며 내부 정밀도를 보존한다. N이나 구간을 바꿔도 기존 T는 유지하고 재확인을 표시한다. 양의 정수가 아닌 N, 미선택·불연속 구간, 구간 변경 후 확인되지 않은 N에는 적용을 비활성화한다. 주기 계산 도움의 중복 적용 UI는 두지 않는다.

양쪽 계산 도움은 입력 영역 아래·그림 위에 같은 폭으로 배치한다. 제목은 `각속도 계산 도움`·`구심가속도 계산 도움`, 내부 펼침 제목은 `관계식과 값 대입`으로 통일한다. 각속도·구심가속도 계산 도움은 일반 관계식과 학생이 입력한 T·r·ω를 대입한 식까지만 보여 준다. 미입력 항목은 빈 네모칸으로 표시하고 입력된 항목은 유지하며, 빈칸을 0으로 간주하지 않는다. 계산 결과 공개·답 자동 입력 기능은 제공하지 않는다. 회전수 옆 주기 미리보기와 명시적 `주기 적용`은 유지한다.

**원운동 개념도:** 위에서 본 원, 중심, 원 위의 물체, 점선 반지름 r, 물체에서 중심을 향하는 구심가속도 a 화살표와 작은 회전 방향 화살표를 표시한다. 원 오른쪽에 관계식 ω=2π/T와 a=rω²를 분수선·위첨자를 갖춘 수식 형태로 배치한다. 원과 수식의 전체 폭을 기준으로 가운데 정렬하고 아래 수식 줄을 없애 높이를 줄인다. 그림 아래의 반지름·구심가속도 수치 줄은 표시하지 않는다. 수치는 위 입력칸에서 확인하며 원 크기·물체 위치·화살표 길이는 고정한다. 부채꼴·시간 단계·회전 재생·축척 조정 안내는 제공하지 않는다. 화면과 PNG·인쇄는 같은 그림 함수를 사용하며 수치 줄을 중복 표시하지 않는다.

### 7. 두 결과 비교와 활동지 기록
입력·비교 제목·그림·활동지 출력에는 **센서로 구한 구심가속도 / 주기로 구한 구심가속도**를 일관되게 사용한다. 두 가속도는 유한한 0 이상의 값이어야 하고, 평균 확인·양의 반지름/주기/각속도·양의 정수 회전수와 재확인 없는 상태가 갖춰져야 결과 비교 탭과 이동 버튼이 함께 활성화된다. 반지름 3 m 초과 단위 주의는 진입을 막지 않는다. 학생의 계산값이 참고 정답과 같은지는 검사하지 않는다.

이미 비교 화면에 있는 상태에서 조건이 깨지면 그 화면에 남되 결과·막대·해석을 초기 빈 표시로 바꾸고 모든 비교 조작을 막는다. 저장된 입력과 해석은 지우지 않으며 조건이 회복되면 복원한다. 구간·계산 탭과 기존 실행 취소·다시 실행은 계속 사용할 수 있다. 미완성 초안은 기존 자동 저장·전체 실험 JSON에 보존하되, 비교 활동지 출력은 유효한 현재 결과에서만 수행한다.

비교 화면은 최종 두 값과 결론에 집중하며 시간·회전수·반지름·중간 계산 요약을 반복하지 않는다. 두 결과 카드와 같은 축척의 막대를 하나의 묶음으로 배치한다. 카드가 좌우로 놓이면 사이에 세로 막대 두 개를, 위아래로 쌓이면 사이에 가로 막대 두 개를 둔다. 값과 막대의 색으로 각 방법을 연결하며 카드 가장자리의 강조선은 사용하지 않는다. 막대 비교의 별도 도움말 버튼은 두지 않는다. 두 막대는 같은 0 기준선에서 시작하고 0에는 길이를 만들지 않는다. 막대 끝에서 가는 보조선을 이어 높이 또는 길이 차이를 보여주며, 축을 잘라 작은 차이를 과장하지 않는다. 격자·눈금·수치 표시는 추가하지 않는다. 숫자보다 단위를 작게 표시하며 공통 단위 표현을 재사용한다. 각 카드의 계산 확인 링크는 해당 입력칸으로 돌아가며 생각 메모를 유지한다.

결과 묶음 아래에 오차 분석 카드를 두고 차이(m/s²)·백분율 차이(%)를 학생이 직접 계산해 입력한다. 공통 숫자 입력칸·단위·경고와 접이식 계산 도움을 재사용한다. 백분율 차이의 탐구 의의는 입력칸 제목 옆 공통 물음표 툴팁에 둔다. 계산 도움에는 공통 수식 표시로 분자에 “두 값의 차이”, 분모에 “두 값의 평균”을 둔 분수와 ×100%를 먼저 보여주고 기호식·값 대입으로 이어진다. 도움은 큰 값에서 작은 값을 빼는 방법, 차이를 두 값의 평균으로 나누어 100을 곱하는 방법과 관계식·학생 값 대입까지만 제공하며 답을 자동 표시하거나 채우지 않는다. 미입력·재확인 중인 차이는 대입식에 빈 네모칸으로 나타낸다. 두 값이 모두 0이면 백분율 차이 입력을 비활성화하고 계산할 수 없음을 안내한다. 두 구심가속도 중 하나의 수치가 바뀌면 차이·백분율 차이 입력을 초기화한다. 같은 수치를 재확인하거나 표기만 바꿀 때는 유지하며 실행 취소로 복원할 수 있다. 차이만 수정하면 기존 백분율 차이에 재확인 표시를 한다. 이 입력들의 미완성·재확인은 비교 화면 진입을 막지 않는다. 입력은 자동 저장·JSON·활동지 출력에 보존하며 미입력은 미입력으로 출력한다. 백분율 차이의 저장 키는 `percentDifference`이며 이전에 주기 기반 값을 분모로 쓴 `relative` 입력은 불러올 때 제거하고 다시 입력하도록 빈칸으로 둔다. 나머지 활동 내용은 보존한다. 이는 학생 결과 사이의 비교이지 정답 판정이나 실험 성공 점수가 아니다.

오차 분석 카드 상단에는 결과 차이를 살펴 실험을 개선한다는 목적과 그래프·측정 과정에서 원인을 찾으라는 안내만 짧게 둔다. 차이·백분율 차이의 의미는 각 툴팁에, 계산 방법과 기호 설명은 계산 도움에 두어 중복을 줄인다. 오차 분석 제목의 툴팁은 유지한다. 백분율 차이 툴팁에는 두 값의 정확성에 관한 부연을 넣지 않는다. 차이·백분율 차이의 각 기호식에 Δa·aₛ·a_T 설명을 함께 두어 어느 도움부터 열어도 이해할 수 있게 한다. 차이·백분율 차이 계산 → 그래프와 측정 과정에서 근거 찾기 → 원인 설명과 다음 측정의 개선점 작성 순서로 안내한다. 차이가 작다는 사실만으로 측정의 정확성을 보장하거나 원인을 단정하지 않는다.

해석 입력은 결과 비교 → 원인 추론 → 설명 점검과 재실험 계획의 세 질문으로 나눈다. “두 방법으로 구한 구심가속도는 얼마나 비슷한가요?”에는 어느 값이 더 큰지 확인하고 차이·백분율 차이를 이용해 얼마나 비슷한지 설명하도록 보조 안내를 붙인다. “두 결과에 차이가 생긴 이유는 무엇일까요?”에는 그래프·측정 과정의 근거를 찾도록 안내한다. 마지막 질문은 “생각한 원인이 오차를 잘 설명하나요? 개선하려면 실험을 어떻게 바꿔야 할까요?”로 간결하게 제시한다. 보조 질문은 “그 원인은 구한 구심가속도를 더 작게 또는 크게 만들까요? 내 결과와 맞는지 살펴보고, 그 원인을 줄여 다시 실험하면 결과가 어떻게 달라질지 예상해 보세요.”로 입력칸 위에 항상 표시한다. 공통 물음표 툴팁 “내 설명 점검하기”에는 회전수를 실제보다 많이 센 경우 계산한 주기와 주기로 구한 구심가속도가 어떻게 달라지는지 묻는 예시만 둔다. 실제 결과 비교와 개선 후 예측은 보조 질문에 남겨 중복하지 않는다. 핵심 사고 과정은 보조 질문에, 구체적인 예시와 확인 관점은 툴팁에 배분하며 추가 입력칸은 만들지 않는다. 별도 입력칸 없이 기존 `improvement` 답을 보존하며 출력에도 설명 점검과 재실험 계획으로 표시한다. 기존 `evidenceText` 답은 첫 질문에 보존하고, 원인 설명은 `differenceReason`에 별도로 자동 저장·출력한다. 이전 활동지의 원인 설명은 빈칸으로 시작한다. 원인 찾기 도움말은 가속도 그래프의 안정성·회전의 일정함·회전수·반지름 측정을 확인할 관점을 제공하며 원인을 단정하거나 결론을 대신 입력하지 않는다. 역할·새 시도는 선택 성찰로 접어 둔다.

선택·입력·해석의 수정은 기존 Workspace·RunStore 자동저장 흐름을 사용한다. 별도의 보관·갱신 버튼이나 갱신 여부 확인은 두지 않는다. 활동지 미리보기·이미지·인쇄는 공통 내보내기 메뉴에 묶고, 누른 시점의 현재 활동지를 복사해 출력한다. 이후 편집은 출력 중인 사본을 바꾸지 않으며 다시 내보내면 최신 입력을 사용한다.

활동지 출력은 두 계산 열·선택 구간·입력과 단위·그림·생각 메모를 포함한다. 접힌 도움말의 예시 답을 학생의 생각으로 내보내지 않는다. 그림은 내보내기 시점의 현재 입력으로 재현한다. 별도 채점·시험 기능은 만들지 않는다.

**일치한 결과의 성찰:** 두 번째 질문 옆의 “두 결과가 잘 일치했어요” 버튼은 비교 화면에 진입 가능한 상태라면 백분율 차이의 수치나 입력 여부와 관계없이 선택할 수 있다. 앱이 성공·실패를 판정하거나 자동으로 질문을 바꾸지 않는다. 선택하면 두 번째·세 번째 질문을 다음으로 교체하고, 같은 버튼의 이름이 “차이 원인 질문으로 돌아가기”로 바뀌어 원래 발문으로 돌아올 수 있다. 화면이 좁으면 질문 옆 버튼을 다음 줄로 배치하며, 전환 뒤에도 버튼의 키보드 초점을 유지한다.

- “두 결과가 잘 일치한 데에는 어떤 실험 과정이 도움이 되었을까요?” — 측정 과정에서 주의한 점을 돌아보고 그래프·측정 기록으로 뒷받침하게 한다. 도움말은 일정한 회전과 회전수·반지름 측정 과정을 돌아보도록 안내하며 성공 원인을 단정하지 않는다.
- “두 결과가 비슷하다는 것만으로 정확하게 측정했다고 볼 수 있을까요?” — 두 값이 실제보다 함께 크거나 작게 나왔을 가능성과 정확성을 더 확인할 측정·비교 방법을 생각하게 한다. 도움말은 반복 측정으로 확인하는 일관성과 센서·측정 방법 점검 또는 신뢰할 수 있는 기준과의 비교로 살피는 정확성을 구분한다.

선택은 활동지의 `comparisonMode`(`difference` / `agreement`)로 Workspace가 소유한다. 일치한 결과의 답은 `agreementReason`·`accuracyReflection`에 따로 보존한다. 전환·수치 변경 시 양쪽 답을 덮어쓰거나 지우지 않으며 기존 자동 저장·실행 취소·JSON 흐름을 사용한다. 이전 활동지는 기본 질문으로 열고 새 답은 빈칸으로 둔다. 활동지 출력은 선택한 질문의 답만 포함하며 전체 JSON에는 두 경로의 답을 모두 보존한다. 비교 진입 조건이 무효이면 전환도 비활성화하고 답은 빈 표시로 두며, 조건이 회복되면 선택과 답을 복원한다.

### 8. 변경·오류·보존 규칙
학생이 계산한 값과 측정 평균·주기 미리보기를 분리해 관리한다. 잘못 계산한 유한 수치도 학생의 탐구 기록이므로 자동 수정하지 않는다. 문법 오류·잘못된 단위 형식은 UI 초안으로 보존하며 수치 결과처럼 취급하지 않는다.

| 변경 | 자료/참고 계산 | 학생 입력과 그림 |
|---|---|---|
| A/B 변경 | Δt·자료 상태 갱신, 평균 다시 구하기 | 이전 N·양쪽 계산 보존, 현재 자료에 대해 재확인 표시. N 재확인 전 주기 미리보기 보류 |
| N 변경 | 주기 미리보기 갱신 | T·ω·a_p 보존·재확인. 왼쪽 영향 없음 |
| r 변경 | 대입 식 갱신 | a_p 재확인. T·ω·왼쪽 보존. 반지름 숫자만 새 조건 반영 |
| 주기 T 적용 | 해당 단계 도움 갱신 | ω·a_p 보존·재확인 |
| 학생 ω 변경 | 해당 단계 도움 갱신 | a_p 보존·재확인, 대입 과정 갱신 |
| 학생 a_s / a_p 변경 | 원자료·측정 평균 불변 | 개념도의 해당 숫자와 학생 결과 비교 갱신 |
| 보기 범위·채널 변경 | 계산·구간 불변 | 입력·근거 유지 |

조건 변경으로 재확인이 필요한 계산 입력칸에는 옅은 붉은 배경을 표시한다. 결과 비교는 모든 재확인을 마칠 때까지 진입을 막고, 이미 열린 경우 초기 빈 상태로 비활성화한다. 별도 재확인 문구·안내 상자·확인 버튼은 두지 않으며, 기존 값을 보존하고 입력칸을 계속 편집할 수 있게 한다. 직접 다시 입력하거나 주기를 적용하면 해당 항목의 표시를 해제한다. 직접 입력하는 값은 재계산한 값이 같다면 해당 입력칸에서 Enter로 확인하며, 초점 이동만으로는 해제하지 않는다. 숫자 형식이 유효할 때만 확인할 수 있고 정답 일치를 강제하지 않는다. 보조 기술에는 조건 변경 전 값이라는 설명을 제공한다. 새 활동지를 만들 때만 입력을 비운다. 이미 내보낸 파일은 이후 입력 변경으로 바뀌지 않는다.

A/B가 확인된 일시정지·재연결·수신 중단·시각 역행을 가로지르면 현재 구간의 계산을 보류한다. 제외한 표본을 포함하면 복원 또는 구간 재선택을 안내한다. 유효한 다른 쪽의 작업·이전 입력·원자료는 지우지 않는다. 평균·결측의 구체적인 정책은 아래 확정 사항을 따른다.

화면 이동·재렌더·다른 활동지 선택·실행 취소·파일 복원에서 입력·출처·재확인 상태를 보존한다. 초안은 입력 중에도 유지하지만 글자 입력마다 저장소 이력을 쌓지 않는다. 저장 실패·읽기 전용 상태는 기존 정책을 따른다. 읽기 전용의 활동지 선택·도움 조회는 화면 임시 상태이며 저장 데이터를 바꾸지 않는다. 키보드만으로 전체 작업이 가능하고, 모든 그림은 숫자·문장 대안을 갖는다. 성분 벡터는 측정 평균에 따라 갱신하고 원운동 개념도는 기호·관계식을 유지하고 학생 입력값은 접근성 설명에 반영한다. 회전 조작은 제공하지 않는다.

## 펌웨어·전송 계약
기존 가속도·자기장 단독 프로그램과 별도로 복합 센서 펌웨어를 등록한다. 같은 루프에서 가속도 X·Y·Z·크기와 자기장 크기를 순차 읽어, 측정 1회당 5개 값을 `Ax,Ay,Az,A크기,B크기` 순서의 CSV 한 줄로 묶어 BLE UART로 전송한다. 두 크기는 기존 단독 프로그램처럼 보드에서 `Dimension.Strength`로 읽어 보내며 앱에서 XYZ로 다시 계산해 대체하지 않는다. 가속도 네 값은 기존과 같이 mg로 전송하고 앱에서 m/s²로 환산하며, 자기장 크기는 µT로 전송·저장한다. 자기장 X·Y·Z는 전송·저장하지 않는다. 완전 동시 측정이라고 표시하지 않는다.

수치 행은 기존 `decodeDecimalChannels`의 필드 수·수치·빈 필드·범위 검사와 채널별 `validity`를 재사용하며 가속도 단위 환산도 기존 상수를 사용한다. 별도 유효성 비트나 새 오류 메시지 형식을 먼저 추가하지 않는다. 수치 범위 검사는 센서 포화 등 모든 하드웨어 오류를 검출한다는 뜻은 아니며, C0에서 확인된 미검출 오류에 한해 장치 상태 확장을 검토한다. 자기장 보정 선택·완료·생략과 재연결 처리는 기존 내장 자기장 준비 모듈의 흐름을 재사용하고, 복합 센서에 맞는 채널·펌웨어·준비 내용만 등록한다. 상태 응답은 기존처럼 측정 행과 구별한다.

기존처럼 측정 1회마다 한 줄을 보내고 다음 측정까지 기다린다. 기존 100ms 대기를 C0의 비교 기준으로 삼고 20/50/100ms 같은 후보 수집 간격은 실제 센서 갱신률·피크 폭·전송량을 실측해 결정한다. BLE UART 조각은 기존 줄바꿈 기준 UTF-8 재조립·행 길이 제한·잘못된 행 뒤 복구를 그대로 사용한다. 이번 활동에는 별도 바이너리 프레임·길이 헤더·배치 전송·수집 및 전송 간격 분리·별도 링 버퍼를 추가하지 않는다.

기록의 작성자는 기존 Session이다. 시작·일시정지·재개·종료, 저장 실패, 연결 시도 구분과 불연속 사건은 기존 경로를 유지하며 보드의 송신 상태와 앱의 기록 상태를 합치지 않는다. 수신 기준 게이트는 정지 중 받은 자료를 소급 기록하지 않지만, 재개 뒤 도착한 행이 보드에서도 재개 뒤 측정됐음을 보증하지는 않는다. 현재 구조만으로 보드 순번의 누락·중복이나 정확한 수집 경계를 확인할 수 있다고 설명하지 않는다. 활동의 주기 측정은 기존 정지·재개·재연결 사건과 확인된 수신 중단을 가로지르지 않는다. 사건을 A/B 구간 판정에 적용하는 처리는 활동 분석에 추가한다.

**확정: 보드 시각·전송 순번·기록 확인 응답을 추가하지 않고 기존 방식을 사용한다.** 측정 행은 5개 값만 전송하며 보드 경과 시각, seq, boot/session ID, 기록 시작·정지·재개 ACK를 추가하지 않는다. 기존 자기장 준비·보정 상태 응답은 유지한다. 시간 그래프·A/B 기준점·회전 주기·구간 집계에는 기존 `Sample.receivedAt`(브라우저 UTC 수신 시각)을 사용하고, 원자료 참조에는 앱이 부여한 `sampleId`를 사용한다. 별도 시간 투영·시각 메타데이터·보드 수집 경계 제어는 만들지 않는다. 이 결정은 통신·기록 방식의 확정이며 실기기 측정 정확도의 검증 완료를 뜻하지 않는다. 수신 시각에 포함된 전송 지연의 변동은 주기 측정의 오차 요인으로 해석한다.

### 제출용 활동지 출력

출력은 화면 폭과 답변 길이에 관계없이 A4 세로 2쪽으로 고정한다. 1쪽에는 선택한 구간의 가속도·자기장 그래프, 측정값과 두 계산 경로, 학생의 계산 설명, 기존 성분·원운동 그림을 담는다. 2쪽에는 두 결과와 막대 비교, 학생이 구한 차이·백분율 차이, 선택한 성찰 질문의 답, 역할·새 시도를 담는다. 파일 이름은 출력 본문·미리보기 제목에서 제외하고 측정 날짜·활동지 번호를 남긴다. 학급·학번·이름은 미리보기에서 입력하고 활동지에 자동 저장한다. 작성자 입력란은 고정된 하단 영역에서 넓은 화면에서는 버튼 왼쪽에, 좁은 화면에서는 버튼 바로 위에 배치한다. 세 항목 중 하나라도 공백이면 저장·인쇄를 막고 짧은 안내와 함께 첫 빈칸에 초점을 옮긴다.

영역의 위치·크기·쪽 나눔을 고정하고 각 영역 안에서 글자를 자동 축소한다. 작성자 정보는 날짜 줄에 배치하고 학급·학번·이름의 값 아래에만 개별 밑줄을 둔다. 상단 여백을 줄여 풀이·서술 영역에 배분하고, 학생 답변은 기본 10.5pt로 표시한다. 질문은 보통 굵기로 낮추고 답변의 내부 여백을 확보한다. 숫자는 굵게, 단위는 더 작고 보통 굵기로 구분하며 보조 글자와 테두리는 인쇄 가독성을 고려한 대비를 유지한다. 긴 답을 생략하거나 추가 쪽으로 넘기지 않으며, 지나치게 작아지는 경우 미리보기에서 안내한다. 측정·계산 입력값과 학생 서술은 네모 테두리로 구분한다. 미작성·보조 계산의 재확인 상태는 그대로 드러내며 참고 정답이나 작성하지 않은 설명을 보충하지 않는다.

결과 보고서로 내보내기는 미리보기를 바로 연다. 미리보기에는 이미지로 저장·인쇄·닫기를 제공하며 같은 양식을 사용한다. 이미지는 두 쪽을 위아래로 연결한 PNG 한 파일로 저장하고 인쇄는 A4 두 쪽을 유지한다. 그래프는 공통 시간 차트와 축 범위 정책을, 성분·원운동·비교 그림과 수식은 기존 앱 요소를 재사용한다. 출력 준비 시 현재 활동지와 구간 자료를 고정하며 출력 이후 변경은 이미 만든 파일을 바꾸지 않는다.

## 저장·재현
기존 불변 Samples, Events, RunStore, Workspace와 근거 저장을 재사용한다. 활동 전용 DB·원자료 복제본·별도 기록 수명은 만들지 않는다. 전체 JSON은 편집 가능한 활동지 상태를 왕복 보존하고 원자료 CSV는 기존 5채널 형식을 유지한다. 활동 결과 PNG·인쇄는 근거의 출처·조건·입력 상태를 표시하며 이를 다시 가져오는 별도 편집 형식은 만들지 않는다.

활동지 상태는 다음을 구별한다.
- 자료 참조: 기록 ID, A/B sampleId·수신 시각, 선택 출처, 자료 상태. 이전 파일의 구간 선정 이유는 호환성을 위해 보존하지만 새 입력칸은 제공하지 않는다. 새 구간은 손잡이·시간 입력으로 직접 확정하며 이전 파일의 자동 후보 채택 출처도 보존한다.
- 조건: 학생이 판단한 N, 반지름과 단위, 고정 g=9.8, 계산·집계 정책 버전. 현재 반지름은 같은 장착 조건에서 한 작성자가 관리하고 근거에는 당시 값을 고정한다.
- 학생 작업: T·ω·a_s·a_p의 입력값, 직접 계산/도움값 채택 출처, 생각·역할 메모, 어떤 조건에서 입력했는지와 재확인 상태. 이전 입력과 미완성 초안을 정답/참고값으로 대체하지 않는다.
- 자료 준비: 구간 평균 확인 상태와 주기 적용 출처를 보관한다. 이전 파일의 도움 사용 이력은 호환성을 위해 유지하되 자동 계산 답은 화면·출력에서 다시 공개하지 않는다.
- 이전 파일의 고정 근거는 호환성을 위해 보존한다. 현재 활동지는 수정하면 자동 저장하며 별도의 보관·갱신 버튼이나 확인 절차를 제공하지 않는다. 보고서는 미리보기를 열 때의 현재 활동지·구간 자료를 사용한다.

수신 시각은 참조 표본과 일치해야 한다. 자동 후보의 임시 목록·그림 좌표·모형 재생 시각은 과학 원자료로 저장하지 않는다. 이전에 채택한 후보의 방법·버전은 출처에 남긴다. 활동지 추가/삭제·입력 수정·재확인 상태도 기존 실행 취소 이력에 포함한다. 전체 실험 JSON v2 안에서 활동지 형식을 검증한다. m 단위 활동 v2 기록은 활동지가 없으면 새 활동지를 시작하며, 이전 cm 기반 활동·활동지 v1 기록은 지원하지 않는다.

## 기존 모듈과 결합
- 센서 정의·codec·공통 런타임: 구현한 5값 전송·단위 환산·보정·연결·기록 계약을 유지한다. 이번 재설계 때문에 펌웨어를 수정하지 않는다.
- 활동 정의: 장치 준비·질문을 제공한다. 활동 전용 계산은 `src/analysis/activities/centripetal.js`, 표시·그림·출력은 `src/ui/centripetal/`에서 소유한다. 공통 화면은 전용 View를 호출하며 물리 관계를 추측하지 않는다. 범용 활동 모듈 등록 체계를 새로 만들지 않는다.
- Session/RunStore/Repository: 기록 수명·원자료·저장 실패 처리의 소유권을 유지한다. 활동지 입력으로 원자료를 수정하지 않는다.
- Workspace: 공통 구간·활동지 조건·학생 입력·참고 계산·재확인·근거·실행 취소를 소유한다. 활동 계산 순수 함수는 UI·장치를 참조하지 않는다. 기존 행별 계산 열에 활동지와 구간 집계를 억지로 넣지 않는다.
- UI: 기존 기록 조작·단위 입력·도움말·메모·원자료 그래프/표·출력 스타일을 재사용한다. 성분/회전 그림은 활동 전용 SVG 등으로 구현하며 새 그래프 엔진·3D 라이브러리·범용 활동지 프레임워크는 도입하지 않는다. 성분 벡터의 비율·각도는 측정 평균을 사용하며 원운동 그림은 기호와 관계식만 표시하고 수치는 입력칸에서 확인한다. 화면·접근성 설명·출력은 같은 모델을 사용한다.
- 수식: [공통 표현 규칙](design/visual-language.md#9-수식기호단위)과 표시 모듈을 사용한다. 센서 성분·각속도·구심가속도의 관계식과 대입식은 활동 안에 정의하며 계산 결과를 자동으로 채우지 않는다. 기호는 이탤릭체, 단위·π는 세운 글꼴로 표시하고 반지름은 입력·저장된 m 값을 그대로 대입한다. 원운동 그림은 조판한 분수식의 실제 폭을 포함해 가운데 정렬하며 PNG·인쇄는 수식 준비를 기다린 뒤 같은 SVG를 사용한다.
- 파일: 학생 입력과 측정값·참고값을 구별해 검증·왕복·출력한다. 일반 센서의 파일·분석 의미는 유지한다.

## 확정 사항과 계산 정책
1. 학생은 N·r·ω·두 구심가속도를 직접 입력하고 앱은 평균·Δt를 제공한다. 평균은 버튼을 눌러 확인하며 주기는 명시적 적용으로 입력한다. 두 구심가속도와 각속도의 도움은 관계식·대입 과정까지만 제공하며 참고 정답은 화면·출력에 넣지 않는다.
2. 성분 그림은 센서에서 출발하는 세 벡터와 직각·보조선으로 관계를 나타내고 중력 길이를 고정한 채 측정 평균에 따라 나머지 벡터의 비율을 갱신한다. 정오 판정·자동 수정은 하지 않는다. A/B·조건 변경은 이전 입력·생각을 보존하고 영향받는 항목만 재확인하도록 한다.
3. 평균은 A/B의 실제 표본을 양 끝에 포함하고, 인접 표본 사이의 직선 보간을 시간에 대해 적분한다. 표준편차도 같은 직선 함수의 제곱 적분으로 계산한다. 화면 반올림값을 계산에 재사용하지 않는다. 표본 사이를 직선으로 보는 가정이지 실제 변화나 불확도의 추정값은 아니다.
4. 구간 안의 중복·역행 시각, 기록 중단·재연결·수신 중단 사건, 제외 표본, 큰 시간 공백은 구간 계산을 보류한다. 공백 기준은 선택 구간의 인접 수신 간격 중앙값의 5배와 1초 중 큰 값이다. 간격이 5개 미만이면 1초를 사용한다. 이 규칙은 수신 불연속 점검이며 보드의 갱신률·주기 정확도를 보증하지 않는다. 새 자료가 붙어도 기존 선택 구간의 기준은 바뀌지 않는다.
5. 같은 구간에 가속도 결측이 있거나 평균이 9.8 이하이면 센서 경로 참고 계산만 보류한다. Δt·N으로 가능한 주기 계산과 학생 입력은 보존한다. 별도 오차 전파·불확도 계산·등속 판정은 추가하지 않는다. 표시값은 기본 소수 셋째 자리까지, 아주 작거나 큰 값은 지수 표기하며 이는 유효 숫자 정확도 보증이 아니다.
6. 활동지 확장 상태는 기존 JSON v2 안에서 별도 버전 2로 검증하며 반지름은 m로 저장한다. 근거의 `linear-time-v1` 정책은 집계·참고 계산의 재현 기준이다. 출력의 수치 항목은 보관된 측정값과 입력으로 재현한다. 원자료 참조·출처·공개 도움·재확인 상태를 보관하고 좌표나 자동 후보 목록을 저장하지 않는다. 피크 보조는 기존 신호 범위 중간 이상 국소 최댓값 판별을 재사용하며 N을 결정하지 않는다.

외부 시계 입력 모드·자동 N·회전별 일괄 측정·활동지 통합 평균·자동 점수·여러 속도/반지름 관계 그래프·실측처럼 보이는 회전 재생은 첫 버전에 추가하지 않는다. 하드웨어 갱신률·검출 설정·정확도는 C0 실측으로 판단한다.

| 단계 | 작업 | 통과 기준 |
|---|---|---|
| C0 | 실제 원판·자석과 기존 수신 방식 검증 | 갱신률·피크·간섭·포화·수신 간격과 독립 시간 기준 비교. 소프트웨어 검사와 구별 |
| C1 | 5값 펌웨어·기록·저장 기반 | 작업 브랜치 구현 상태는 문서 첫 절 참조. 재설계에서 유지 |
| 설계 검토 | 활동지·입력·도움·물리 그림 확정 | 2026-10-30 설계·장면별 이미지 승인. 학생 판단과 앱 계산 구분 |
| C2 | 기록 본문·공통 구간·두 열 활동지와 입력/보존 | 수동 A/B·N, 키보드/터치, 미완성·수정·실행 취소·자료 변경 재확인 |
| C3 | 동일 구간 집계·계산 도움·반응형 그림·비교·근거/출력 | 원자료/학생 입력/참고값 구별. 조건 변경 영향 분리. JSON 왕복·그림/단위 재현 |
| C4 | 여러 속도·반지름 관계 탐구 | 후속 확장, 첫 버전 필수 아님 |

검사는 변경 범위 중심으로 수행한다. 다음 사용자 피해를 막는 검사를 기존 계약 검사에 보완한다.
- 공통 구간 도구로 구간을 정하고 N을 직접 입력할 수 있으며, 피크 보조나 파일 복원으로 N·답안이 자동 채워지지 않는다.
- 주기와 가속도가 같은 구간을 참조하며 일시정지·재연결·공백·원자료 제외를 조용히 무시하지 않는다.
- 학생 계산값은 보존하며 성분 벡터의 비율은 측정 평균을 기준으로 한다. 원운동 그림 아래에는 입력값을 중복 표시하지 않는다. 과학 단위·값의 보존을 검증하고 그림의 장식 좌표·색·치수는 자동 검사로 고정하지 않는다.
- A/B·N·r·T·ω 변경 시 필요한 입력만 재확인 상태가 되고 과거 근거·다른 쪽 작업은 보존된다.
- 빈칸·계산 불가·0·음수·큰 값·반올림 차이에서 잘못된 도형/NaN/무한대·오류 채점·자료 삭제가 발생하지 않는다.
- 저장 실패·화면 이동·실행 취소·JSON 왕복에서 학생 입력·출처·조건이 보존된다. 측정값과 학생 계산값이 파일에서 섞이지 않는다.
- 데스크톱/작은 화면에서 두 과정·공통 출처·최종 비교를 이해할 수 있고 키보드와 숫자/문장 대안으로 그림 없이도 완료할 수 있다.

실기기 검증과 학생 대상 수업 검증은 아직 수행하지 않았다. 디자인 시안의 예시 데이터·계산은 BLE 측정 결과가 아니다.

### 공통 측정 UI 적용

연속 측정 탭은 유지하되 한 점씩 측정 탭·연속 기록 토글·한 점 기록 버튼과 기록표는 숨긴다. 새 실험은 연속 기록으로 고정하고 전용 분석은 연속 원자료를 사용하므로 분석 자료 선택창을 숨긴다. 세부 보존 규칙은 [활동별 측정 방식](point-recording-design.md#활동별-측정-방식)을 따른다.

### 활동지 목록과 관리

자료 이름·이력 조작 줄의 공통 드롭다운에서 활동지를 선택한다. 목록 하단의 **+ 새 구간으로 분석**으로 활동지를 추가하며, 각 이름 옆 휴지통은 공통 확인창을 거쳐 해당 활동지만 삭제한다. 다른 활동지와 측정 원자료는 보존하고 마지막 활동지의 삭제는 비활성화한다. 드롭다운 옆 도움말로 구간별 분석·선택·삭제 방법을 설명한다. 별도 원자료 도구 진입은 제거한다. 상단은 원자료 / 구간·계산 / 결과 비교 탭으로 구성하며 기본 진입은 구간·계산이다. 원자료 탭에는 전체 기록의 공통 표만 표시하고 현재 분석 구간의 행을 강조한다. 자료 번호·경과 시간·가속도 크기·자기장 크기 뒤에 가속도 X·Y·Z(m/s²)를 더 좁은 열로 배치한다. 활동지 선택·이력 조작은 모든 탭에서 유지한다.

### 구간 선택의 피크 보조

자동 후보 목록·도움 버튼은 제공하지 않는다. 구간 손잡이를 드래그할 때 화면상 6px 이내의 가까운 자기장 국소 최댓값에 가볍게 붙인다. 멀어지면 자유롭게 움직이고, 다른 끝점을 넘어서는 피크에는 붙지 않는다. 시간 직접 입력과 키보드 이동에는 이 보조를 적용하지 않는다. 후보 판별은 기존 신호 범위 중간 이상 국소 최댓값 규칙을 재사용하며 회전수·주기·구간을 자동 확정하지 않는다.
