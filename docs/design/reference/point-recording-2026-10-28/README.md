# 한 점 기록 UI 참고 시안

2026-10-28 사용자가 대화에 첨부한 시안 6장을 원본 그대로 보관했다. 화면 흐름에 맞춰 파일명만 정리했으며 크기·색·내용은 변경하지 않았다. 첨부 순서, 원래 파일명, 크기, SHA-256은 [sources.json](sources.json)에 기록했다. 제작 도구·제작자·별도 라이선스는 전달받지 않았다.

시안은 배치와 시각적 위계의 참고 자료다. 이미지 속 예시 수치·조작부를 확정 요구사항으로 취급하지 않는다. 기능 계약은 [한 점 기록 상세 설계](../../../point-recording-design.md), 공통 UI 기준은 [시각 디자인 문법](../../visual-language.md)을 따른다. 현재 구현과의 차이는 [P2 UI 정리 검토](../../review/point-recording-p2.md)에 정리했다.

| 파일 | 원래 첨부 순서 | 내용 | 관련 단계 |
|---|---:|---|---|
| [01 수동 측정](01-manual-measurement.png) | 1 | 현재값·방향 성분, 조건 입력, 한 점 기록 표 | P2 |
| [02 연속 측정](02-continuous-measurement.png) | 6 | 연속 기록 중 한 점 기록, 시간 그래프의 기록 표식 | P3 |
| [03 한 점 분석](03-point-analysis.png) | 4 | 조건–센서값 관계, 표·그래프 선택, 선택 기록 상세 | P4 |
| [04 연속 원자료 추적](04-continuous-origin.png) | 3 | 선택 기록의 원래 시점과 연속 자료로 이동 | P4 |
| [05 편집·오류](05-editing-errors.png) | 2 | 기록 중 편집, 조건 설정, 잘못된 값, 연결 끊김 | P2 |
| [06 모바일](06-mobile.png) | 5 | 작은 화면의 측정·편집·분석 | P2–P4 |

이 경로는 설계 참고용이며 앱에서 불러오는 실행 자산이 아니다. 시안의 로고·아이콘을 잘라 별도 자산으로 추가하지 않고 기존 공통 자산과 조작부를 재사용한다.
