## 검토 범위와 한계

- 같은 실험과 선택 구간의 출처가 분석 장면마다 이어지는지, 측정 그래프와 계산 활동지의 역할이 구별되는지 시각 검토했다.
- 이미지 도구의 수학 도식은 구현 기준 좌표가 아니다. 성분 삼각형의 직각 위치는 수정했으나 길이 비율·회전 각도·비교 화살표의 축척에는 근사 표현이 남아 있다. 실제 UI는 학생 입력에서 수학적으로 계산한 도형을 사용해야 한다.
- 예시 주기 1초와 반지름 0.20m의 참고 가속도는 반올림 전 4π²×0.20으로 계산한다. 화면 중간값 6.28은 표시용이다. 두 결과 7.35와 약 7.90의 차이는 약 0.55m/s², 상대 차이는 약 6.9%다.
- 화면 속 입력·버튼·도움 단계와 이동 조건은 확정 계약이 아니다. 특히 미완성 결과의 보관과 자유로운 이동은 [활동 설계](../../../centripetal-acceleration-design.md)의 보존 원칙을 따른다. 이미지의 비활성 버튼을 이유로 기존 작업 이동·저장을 차단하지 않는다.
- 이미지 생성 단계에서는 앱 코드·펌웨어를 변경하거나 앱 검사를 실행하지 않았다. 이후 사용자가 설계와 시안을 승인하여 작업 브랜치에 구현했다. 현재 구현·검증 범위는 [활동 설계](../../../centripetal-acceleration-design.md)에 기록한다.

## 생성 지침

[공통 지침과 장면별 프롬프트](prompts.md). 현재 앱 모의 장치 실행 화면을 참조했고, 2번부터는 앞 장면도 함께 참조하여 일관성을 유지했다. 3번은 성분 그림·각도 표현 수정본을 채택했다.
