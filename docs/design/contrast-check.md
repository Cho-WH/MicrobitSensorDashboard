대비는 상대 휘도 기반 `(L밝음 + 0.05)/(L어두움 + 0.05)`로 계산했다. 일반 글자 4.5:1, 비텍스트 경계 및 중요한 그래픽 3:1을 참고한다. 폰트 렌더링, 광원, 반투명 합성, 키보드 초점, 프로젝터 상태는 별도 실측 검토가 필요하다.

현재 입력 경계는 경계만으로 3:1을 충족하지 않는다. 온도·바이올렛 자료색을 그대로 사용하는 작은 범례/축 글자도 일반 글자 4.5:1에 못 미친다. V2는 채택 화면을 유지하며 규칙을 분리한 단계로, 이 항목을 통과로 처리하지 않는다. V5에서 작은 글자용 색·입력 식별 경계와 실제 합성 배경을 함께 조정한다. 준비 B의 초점선은 밝은 파랑으로 구분했다.
