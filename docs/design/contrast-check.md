# Luminous Lab 색상 대비 기준 (시안 후보)

아래 값은 불투명 sRGB 색상 조합의 계산치로, 완성된 화면의 접근성 인증 결과가 아니다. V1 기준 화면에서 실제 합성 배경과 글자, 조작 상태를 확인한 뒤 다시 검토한다.

| 용도 | 전경 | 배경 | 대비 |
|---|---|---|---:|
| 오렌지 버튼 글자 | `#0B1F3B` | `#FF7A45` | 6.38:1 |
| 흰 글자/오렌지 (사용하지 않음) | `#FFFFFF` | `#FF7A45` | 2.59:1 |
| 작은 오렌지 라벨 | `#B54416` | `#FFFFFF` | 5.52:1 |
| 오렌지 그래프 선 | `#D65A20` | `#FFFFFF` | 3.93:1 |
| 작은 코발트 라벨 | `#1D4ED8` | `#FFFFFF` | 6.70:1 |
| 작은 바이올렛 라벨 | `#6740CF` | `#FFFFFF` | 6.54:1 |
| 보조 글자 | `#53657D` | `#F6F8FC` | 5.60:1 |
| 입력 경계 | `#7F8DA4` | `#FFFFFF` | 3.36:1 |
| 코발트 자료선 | `#246BFD` | `#FFFFFF` | 4.57:1 |
| 바이올렛 자료선 | `#7C5CFF` | `#FFFFFF` | 4.35:1 |
| 정상 상태 글자 | `#137D55` | `#FFFFFF` | 5.13:1 |
| 오류 글자 | `#B42335` | `#FFFFFF` | 6.50:1 |
| 남색 제목 | `#0B1F3B` | `#F6F8FC` | 15.51:1 |

대비는 상대 휘도 기반 `(L밝음 + 0.05)/(L어두움 + 0.05)`로 계산했다. 일반 글자 4.5:1, 비텍스트 경계 및 중요한 그래픽 3:1을 참고한다. 폰트 렌더링, 광원, 반투명 합성, 키보드 초점, 프로젝터 상태는 별도 실측 검토가 필요하다.

참고: [WCAG 명도 대비](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).
