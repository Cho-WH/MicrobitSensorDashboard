# Luminous 디자인 적용·검증 기록

2026-10-25 V2–V5 적용과 후속 UI 구조 전환을 마쳤다. 현재 규칙은 [시각 디자인 문법](../visual-language.md), 실행·검토 방법은 [개발 안내](../../../dev/design/README.md)를 따른다. 이 문서는 최종 결정과 당시 검증 근거만 기록한다.

## 채택한 방향

- 사용자 기준 시안을 바탕으로 준비는 B안의 남색 장면, 측정·분석은 밝은 자료 표면을 채택했다. [A/B 비교](../review/v1/preparation-comparison.md)와 [기준 이미지](../reference/approved-moodboard.png)를 보존한다. 이미지 속 수치·상태는 기능 명세로 사용하지 않는다.
- A안은 사용자 선택의 비교 자료로 실행 가능한 개발 경로에 남겼다. 운영 앱에는 테마 선택이나 옛 측정 UI 분기를 두지 않았다.
- 기존 장치·활동 자원, 서체·아이콘과 라이선스를 유지했다. 준비의 설치·연결·수신·보정 상태와 원자료·저장·계산 계약은 외형 개편으로 바꾸지 않았다.
- 작은 채널 글자와 자료선의 색 역할을 분리하고 입력 경계·초점을 보강했다. 계산 근거는 [대비표](../contrast-check.md), 최종 시각·접근성·성능 관찰은 [V5 검토](../review/v5/review.md)에 있다.

## 기본 UI 구조 전환

| 결정 | 이유와 결과 |
|---|---|
| 고정 HTML·공통 시작 경계 | 선택 테마를 덧씌우던 구조를 정리해 최종 틀·초기 스타일을 HTML에서 선언했다. 준비 완료 전 조작, 자원 실패와 대체 서체를 검사하며 앱 시작 경로를 공유했다. |
| CSS 소유권 통합 | 중복 Luminous CSS 4개와 이전 별칭을 담당 화면·공통 조작 CSS로 통합했다. A안만 개발용 스타일로 분리하고 기본 앱에서 요청하지 않음을 확인했다. |
| 공통 공간 배분 | 측정·원자료·관계·해석의 높이 계산을 공유했다. 최소 읽기 크기를 유지하며 긴 내용·작은 화면·확대에는 스크롤을 허용했다. Canvas가 이전 높이로 배치를 밀어내던 오류도 수정했다. |
| CSS 전달 통합 | 개발 서버와 정적 빌드가 같은 결합 함수를 사용하도록 했다. import 순서·상대 자원 주소·A안 대체를 유지하고 순환·미지원 import는 실패 처리했다. |
| 독립 브라우저 검사 | 기존 제어 환경에서 단순 HTML iframe도 연속 탐색 시 멈췄지만 같은 서버의 독립 Chromium에서는 완료됐다. 실행 환경 문제로 분리하고 기존 검증 조건·앱 준비 판정·3D 출처 검사를 유지했다. 브라우저 내부 원인은 확정하지 않았다. |

### 구조 전환 검증과 관찰

- 초기화·해석 배치 보완: 타입·빌드 및 독립 Chromium 8개 검사(기존 묶음 6개와 실제 페이지 2개) 통과. 기존에 실패했던 묶음도 통과했다. 실제 네트워크 요청 중단으로 3D 실패·배선표 복구·재시도를 확인했다.
- CSS 통합: 홈·소개·준비 A/B·측정·설정·분석·저장 목록의 1366/390px 28조합 비교, 기존 브라우저 묶음 11개와 실제 페이지 2개 통과. 공통 UI CSS 원문은 약 170.5→146.6KB로 감소했다(압축 전·센서별 CSS 제외).
- 공간·전달 통합: 타입·빌드, 스타일 결합/하위 경로 단위 3개, 관련 브라우저 묶음 7개와 실제 페이지 2개 통과. 1366/1920/2560px 자료 화면, 1024/390/320px 재배치·200% 글자, 개발/빌드 하위 경로의 홈·센서·활동 6개 진입을 확인했다.
- 로딩 관찰: 홈·내장 온도·게이뤼삭 각 3회, 매번 새 Chromium 환경에서 CSS 요청마다 100ms 지연을 주었다. CSS 요청은 14→2개, 9회 중앙값은 첫 내용 표시 308→188ms, 앱 준비 421→322ms였다. 세 경로 모두 최초 화면에서 3D 자원을 요청하지 않았다.
- 갱신 관찰: 모의 4채널 600→700행에서 마지막 가상 행·차트 수명을 보존했다. 정지 1.2초간 재그리기 0회, 해당 실행의 Chart update 중앙값 3.3ms/p95 4.1ms였다.

성능 수치는 해당 PC·조건의 관찰값이며 보장값이나 고정 합격 기준이 아니다. 화면·모의 검사로 실물 USB/BLE, 실제 프린터·프로젝터, 다른 브라우저 엔진 및 전체 접근성 인증을 대신하지 않는다. 반복 작업 지시와 중간 디버깅 절차는 제거했으며 당시 원문은 Git 이력에서 확인할 수 있다.
