# MLX90393 외장 자기장 도구

2026-10-30 합의 설계. 구현·검증 상태는 아래에 구분한다.

## 사용자 흐름

- Adafruit MLX90393 STEMMA QT(4022) 한 개와 QT–개별 암 소켓 케이블(4397)을 사용한다. 3V/GND/P20(SDA)/P19(SCL) 배선표와 기존 설치·연결·수신 확인을 재사용한다. 3D 자산은 이번 구현 범위에 넣지 않는다.
- 연결하면 작은 변화 모드로 바로 미리보기 한다. 기존 준비 미리보기 및 장치·실험 설정에 동일한 측정 모드 선택기를 제공한다. 선택지는 작은 변화(기본, `normal`), 강한 자석(`wide`) 두 개다. 게인·해상도·필터·주소·인터럽트는 노출하지 않는다.
- 두 프리셋 모두 100ms 목표 주기다. 범위 확대는 분해능을 낮추며 정확도 향상을 뜻하지 않는다. 범위 자동 변경과 고속 파형 측정은 제공하지 않는다.
- ‘영점 맞추기’와 배경 자기장 차감은 제공하지 않는다. 이는 센서 보정이 아닌 앱의 선택적 계산이므로 준비 단계에서 요구하지 않는다. 배경값 평균·벡터 차감 로직만 [개발용 보관 파일](../dev/experiments/magnetic-background.js)에 분리한다. 앱 실행·빌드·설정 저장에는 연결하지 않으며 향후 탐구 활동의 사용 여부는 미정이다.
- 첫 기록 이후 측정 모드는 고정한다. 일시정지·추가 측정·재연결에서도 유지한다. 새 실험은 현재 설정·연결을 유지하면서 편집을 다시 허용한다.
- XYZ 성분과 자기장 크기, 총 4개 채널을 표시·저장·분석·CSV에서 공통으로 사용한다. 크기는 세 성분의 벡터 크기이며 기본 그래프에는 크기만 선택한다. 원래 값/표시용 값으로 중복하지 않는다. 전체 JSON의 센서 설정에는 프리셋 버전과 선택한 모드만 보관한다.

## 구현 경계

- 센서 모듈이 프리셋·단위 변환·설정 UI·응답 규약을 소유한다. 공통 Transport의 선택적 준비 세션을 확장하여 설정 복원, 응답 확인, 수신 허용 여부를 판단한다. UI 제어기는 기록 전 변경만 허용하고 context.setup.sensorSettings에 확인된 설정을 보관한다.
- 설정 응답 전 수치를 기록하지 않는다. 설정이 바뀌면 수신 확인과 미리보기·한 점 후보를 초기화하고 새 값부터 확인한다.
- 재연결은 저장된 설정을 다시 적용한다. 실패하면 기록을 허용하지 않고 오류를 제공한다. 지원하지 않는 저장 설정을 기본값으로 몰래 대체하지 않는다.
- 원자료·저장·CSV·분석의 기존 채널 경로를 사용한다. 센서 전용 저장소나 차트는 만들지 않는다.
- 보드 명령·채널·수치 변환은 [공통 센서 프로그램 규약](sensor-program-contract.md), 빌드·산출물은 [펌웨어 안내](../dev/firmware/README.md)에 기록한다.

## 프리셋 후보와 근거

HALLCONF=0xC, TCMP_EN=0, DIG_FILT=6, OSR=2, OSR2=0. 일반은 GAIN_SEL=7/RES=0(XY 0.150, Z 0.242 µT/LSB), 강한 자기장은 GAIN_SEL=0/RES=1(XY 1.502, Z 2.420 µT/LSB). 모두 signed 16비트로 해석한다. ADC 끝값과 물리 한계(각 축 50mT)를 정상 측정으로 쓰지 않는다. 실제 축별 유효 범위·정확도는 실물 검증 전이다. UI에 ±5/±50mT를 정밀 보장치로 표시하지 않는다.

TXYZ 변환의 전형값은 51.38ms다. 최대 기동 시간·발진기 허용 오차를 포함해 62ms 대기한 뒤 읽고, 처리 시간을 뺀 나머지만 쉬어 100ms를 목표로 한다. 시간은 앱 수신 시각이며 정확한 10Hz 보증이 아니다.

- [Melexis datasheet rev012](https://media.melexis.com/-/media/files/documents/datasheets/mlx90393-datasheet-melexis.pdf): 표 12/17/19/21, 명령·상태·계수·시간·부호 형식.
- [Adafruit 보드 안내](https://learn.adafruit.com/mlx90393-wide-range-3-axis-magnetometer?view=all): 배선·주소·범위.
- [MakeCode 확장 고정 검토본](https://github.com/dangallichan/microbit-extension-melexis90393/tree/fe1299f88e42a83e4757b6c860e710b2f4bf46c4): 구조 참고. 전체 기능을 의존성으로 들이지 않고 데이터시트에 근거한 필요한 드라이버만 구현한다. 원본의 미완료 실물 검증을 이 앱의 검증으로 대체하지 않는다.

## 상태

2026-10-30: 센서 등록·배선표·공통 준비/설정 UI·프리셋·기록 잠금·복원·센서 프로그램 및 설치 산출물을 구현했다. 이후 사용자 합의에 따라 배경값 기능을 실행 경로에서 제거하고 4개 채널로 정리했다. 펌웨어와 통신 형식은 변경하지 않았다. 초기 펌웨어의 HEX/BIN 일치·공통 런타임 확인은 통과했다.

UI·채널 정리 후 관련 단위 검사 12개(보관 계산 2개 포함), 타입 검사·앱 빌드와 브라우저 모의 검사 6개를 통과했다. 데스크톱/320px에서 준비·측정·설정 창을 시각 확인했고, 4채널 기록·CSV 수치 보존·새로고침 후 재연결·모드 잠금·새 실험에서 모드 유지/변경을 확인했다. 공통 준비 및 DS18B20·내장 자기장 경로도 회귀 검사했다.

실기기 정확도·축 방향·필드 범위·잡음·BLE 동시 동작·측정 주기·USB/무선 설치는 미확인이다. 3D 센서 그림 및 특화 활동은 이번 범위에 포함하지 않았다. 실물에서는 두 프리셋, 포화 후 복귀, 케이블 분리·재연결, 기록 추가·중단을 확인한다.
