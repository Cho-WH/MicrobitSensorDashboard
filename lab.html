저장된 실험 파일은 이 브라우저에서도 열어 분석할 수 있어요.

Bluefy는 Web Bluetooth를 제공하는 별도 브라우저 앱이에요. 설치 후 이 페이지의 주소를 Bluefy에서 열어 주세요. 이 실험실과의 실물 연결은 아직 확인하지 않았어요.

micro:bit에는 해당 센서 프로그램이 먼저 설치되어 있어야 해요. Bluefy 설치만으로 센서 프로그램이 설치되지는 않아요.

다른 브라우저에는 저장된 실험이 자동으로 옮겨지지 않아요. 필요한 자료는 실험 파일로 저장해 옮겨 주세요.

                  연결 도움말

                  micro:bit 연결이 잘 안 되나요?

                  목록에 micro:bit가 보이지 않나요?

                  전원이 켜져 있는지 확인하고 컴퓨터 가까이에 두세요. 연결을 끊은 직후라면 잠시 기다렸다가 다시 찾아보세요.

                  다른 곳에서 연결 중인가요?

                  micro:bit를 사용하는 다른 탭이나 앱을 닫고 다시 시도하세요.

                  그래도 연결되지 않나요?

                  micro:bit 뒤쪽의 리셋 버튼을 한 번 누르거나, USB 케이블과 배터리를 모두 분리해 전원을 다시 연결한 뒤 시도하세요.

                  USB 설치 도움말

                  보드가 목록에 없어요

                  micro:bit V2를 데이터 전송용 USB 케이블로 연결해 주세요. 충전 전용 케이블로는 설치할 수 없어요. 다른 USB 포트나 데이터 케이블로도 확인해 보세요.

                  연결은 되는데 설치가 안 돼요

                  보드를 사용 중인 다른 탭이나 프로그램의 연결을 해제한 뒤 다시 시도하세요. 현재 설치가 진행 중이라면 완료되거나 오류가 표시될 때까지 기다려 주세요.

                  다른 방법으로 설치하고 싶어요

                  컴퓨터에서 보드가 MICROBIT 드라이브로 보인다면 파일을 복사해 설치할 수 있어요. 휴대폰·태블릿에서 파일을 받는 것만으로 설치되지는 않아요.

                  1. 아래 버튼으로 선택한 센서의 프로그램 파일을 받으세요.
                  2. micro:bit V2를 컴퓨터에 USB로 연결하고, 받은 .hex 파일을 MICROBIT 드라이브에 복사하세요.
                  3. 복사가 끝나고 보드가 다시 시작할 때까지 기다린 뒤, 이 창을 닫고 이미 올바른 프로그램이 있어요를 선택하세요. 다음 단계에서 Bluetooth 연결과 새 측정값을 확인합니다.

                  드라이브가 보이지 않으면 먼저 케이블과 USB 연결을 확인해 주세요.

                  기록·저장을 마치고 장치 연결을 해제한 뒤 실제 실험의 준비 화면에서 파일을 받을 수 있어요.
